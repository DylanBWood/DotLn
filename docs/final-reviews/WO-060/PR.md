# WO-060

Nothing in the runtime could hold a tracked-work artifact: the `SourceAdapter` port in product 03 was prose, and gate G of the critical path, intake from an issue into a story contract, had no typed input to start from. This pull request lands WO-060: `SourceBundle` v1, a compiler contract that carries one artifact's sections, discussion, image references and revisions as data, decodes it positively, hashes it canonically, and screens it against a declared set of secret shapes and link forms before anything downstream reads it.

- **One new module, `packages/compiler/src/source-bundle.ts`, and one export line.** `decodeSourceBundle(value, { allowedHosts })` returns a result and never throws on input: a malformed value refuses with the first failing path and a fixed-vocabulary reason, a screened value refuses with every finding's path, byte offsets and span, and an accepted bundle is frozen, in canonical order, with an `fnv1a64:` equality receipt over domain-tagged canonical JSON. Spans are half-open UTF-8 byte ranges into one section's or entry's text; authors are role labels; images are references by content hash with no bytes ([D003](../../evidence/WO-060/decisions.md#wo-060-d003--the-contract-byte-spans-one-id-namespace-input-order-refusals-a-canonical-accepted-bundle)).
- **The screen is data, and it says what it does not claim.** `SOURCE_SECRET_SHAPES` declares eight shapes (a private-key block header, a Bearer credential, and GitHub's `ghp_`, `github_pat_`, `gho_`, `ghu_`, `ghs_` and `ghr_` token forms, each taken from the vendor's public documentation) and `SOURCE_URL_FORMS` declares two link forms (scheme-authority and `www.` autolink) whose host must be on the caller's allowlist; an empty allowlist refuses every link. Any other string passes: the module header, product 03 §Ports and a limits fixture name an unprefixed 40-hex token, a JWT without the Bearer word and a password in the userinfo of an allowed URL as strings v1 decodes ([D004](../../evidence/WO-060/decisions.md#wo-060-d004--the-screens-declared-set-each-pattern-from-its-public-source)).
- **Fixtures fix the claim.** `packages/compiler/fixtures/wo060-source-bundles.json` holds six valid bundles with pinned hashes, eight malformed bundles with their refusal paths, one refusing bundle and its clean twin for each of the ten declared shapes and forms, and the limits bundle. Twelve tests check them, including 41 host-reading cases a judge would try (userinfo, ports, case, trailing punctuation, backslashes, IP literals, percent-encoding) and a resolver over all 64 fixture spans; the criterion 2 test asserts that the fixture cases equal the declared ids exactly, so the code and the fixtures cannot drift apart. Every issue, name and token-shaped string is synthetic.
- **Release and re-mints.** Application `v0.53.0`, a minor over `v0.52.10`; `@dotln/compiler` 0.19.4 to 0.20.0 for the new export, with the skeleton and console pins and the lockfile following and neither consumer's version moving. The compiler label enters the feedback policy hash, so the authority, artifact-identity and verification editions are re-minted deterministically as WO-060 revision 001, the feedback edition is carried from WO-162 with no live episode, the four console self-host fixture files follow the label, and the generated hooks and manifest pin a new runtime snapshot ([D005](../../evidence/WO-060/decisions.md#wo-060-d005--registration-the-harness-and-the-re-mints), [D006](../../evidence/WO-060/decisions.md#wo-060-d006--release-application-v0530-and-compiler-0200)).
- **Write-backs in place.** Product 03 §Ports gains 721 bytes inside the `SourceAdapter` bullet and product 10 §Separate version axes gains 285 bytes for the `source-bundle-v1` contract axis, against limits of 800 and 300; both publication locks are refreshed ([D007](../../evidence/WO-060/decisions.md#wo-060-d007--write-backs-within-the-document-ceilings)).
