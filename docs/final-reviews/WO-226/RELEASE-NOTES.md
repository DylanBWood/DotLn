## Release overview

Application v0.90.0 lets an exported instance's kit work after its update without a hand step. The operator's own instance met the gap on 2026-10-21: a release close withheld on `ENOENT tsconfig.json` because the emitted recovery tried a source build an export cannot run, a bootstrap the session had to remember after each merged update, three texts telling an export to run that build, a publish admission withheld because the order had edited its own registration's gate command, a piped helper spelling that left no row and no advisory, a dispatch pasted as a block that left a planning pass without its role, and no way to ask for the newest model. This release restores the carried runtime where a build was tried, finishes an update with one command, renames every build advisory an export can see, narrows the admission to the publication fields, names a near-miss spelling, reads a dispatch from the first line of a paste, and adds an opt-in Fable 5.1 worker beside the unchanged pinned worker.

Audience: operators of exported instances taking this starter release, above all one whose session finishes updates and closes releases; operators of this repository who dispatch planning passes and read the role text; and the planner who reads the boarded follow-ups and the reopened SessionStart candidate.
