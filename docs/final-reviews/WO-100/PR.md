# WO-100

The resident can now take on maintenance work nobody asked for in the moment, inside limits the operator set in advance. A `portfolio` in `dotln.config.json` is reviewed text naming the 5S mechanics allowed unattended (Sort, Shine and Standardize as compiled today), the repository-relative surfaces, an effect and file ceiling for each presence phase, a budget of episodes, wall time and reported tokens, and the exact verification commands for each candidate kind. `deriveWorkOrders` is pure: each WO-119 candidate becomes exactly one bounded order, a `ProductSuggestion`, a `NeedsHuman` question, or waits for a phase whose ceiling admits it. A resident bound to a portfolio activates the next untried order with a `host-policy` grant, materializes it through WO-120 as a durable record in the index, changes source through one WO-052 source-change host and has the change judged by one WO-054 verification host. The presence curve advances only after an admitted pass.

**Nothing is derived outside the portfolio.** An order's surfaces are the candidate's files plus any declared home, and its size is their count. Its envelope is the phase ceiling intersected with the compiled phase's effective envelope, minus anything a source-change writer may not carry. `admitPortfolio` checks every ceiling against the compiled floor and its phase and requires a writer unit in each named phase before the resident accepts a binding; the configuration loader also refuses a ceiling outside the named repository's registered authority profile. A mechanic the portfolio does not name, or a path outside its surfaces, becomes a suggestion. An obligation no writer can carry (Sort's deletion of a stale generated file), or a kind with no verification command, becomes `NeedsHuman`. The WO-120 contract is phase-free, so one candidate keeps one durable identity whichever phase derives it.

**The curve moves only on verified work.** `PortfolioOrderActivated` records the order, its grant and its WO-120 key before anything runs, and the fold recomputes that activation from the recorded discovery, binding, phase and budget and refuses a log that differs. A Sort move is checked by the host first: the diff must be exactly the old path removed and the home added with the same blob, or the order fails with no verifier dispatched. The pass rule is RepairHost's: no human escalation, every criterion evaluated and passing, and no finding. Anything else, including a refused change or a lost episode, resets the curve to its first phase. Once episodes, wall time or reported tokens are spent, the next portfolio phase records a `ScriptEpisodeRefused` NoOp naming the exhausted resource, and nothing dispatches past it.

**External model selections moved to Opus 5.5 and GPT-6 Sol.** At the operator's direction during implementation ([D007](docs/evidence/WO-100/decisions.md#wo-100-d007), corrected by [D008](docs/evidence/WO-100/decisions.md#wo-100-d008)), every active external-CLI selection of Claude Fable 5.1 now selects `claude-opus-5-5` at `xhigh`, and every GPT-6 Astra selection selects `gpt-6-sol` at `xhigh`. That covers the Entropy Reducer's compiled reviewer (Seisō version 2, with a recorded migration in the authority and artifact-identity editions), the `npm run entropy` and `npm run plan -- refute` defaults, the probe and evidence scripts, and the documents that state them. Historical receipts, recorded evidence and Claude Fable 5 selections keep their bytes. Defaulting always-on agents to GPT-6 Luna or the latest Claude Sonnet at `xhigh` is recorded as a WO-111 candidate, because the resident has no default model yet.

**What a reviewer should know.** No production host binds the portfolio's execution ports yet: today's `dotln resident` reports a portfolio actor unavailable, and the live unattended hour is WO-111's. WO-052 checks committed paths only by surface prefix, so nothing counts a Shine or Standardize change's files against the order's size or refuses a file turned into a directory. That is inherited behaviour, boarded up with a follow-up due before WO-111 runs a portfolio on an operator repository ([D016](docs/evidence/WO-100/decisions.md#wo-100-d016), `FUP-a05fb27e0e8f9bcf`). The budget is an admission budget charged when an episode ends, so the last admitted episode can overrun what remains, and no current host reports tokens. A candidate is attempted once per portfolio version and bound base. The `portfolio` suite runs only outside a harness sandbox.
