# In an instance the kit advises where it used to stop work that was not at risk: every stop has a level its owner sets, and the author's rules are a layer to keep or remove

An exported instance is no longer denied a tool call, and its gate no longer fails, for a reason that guards the kit's own records, a property of the machine or a budget. This is [WO-287](../../work-orders/WO-287-what-an-instance-meets-lands-as-one-order.md), five parts under one activation, planned as the minor `v1.4.0`. Core, which builds the kit, refuses on every stop as before.

**Every stop has a level (Part A).** One build-free table, `packages/skeleton/src/stops.mjs`, holds each stop the kit ships with an id, a class and what it protects. One line of `dotln.config.json` sets its level: `refuse`, `advise` or `off`. In an instance a stop of the class `record`, `host` or `bound` advises and the work goes on, in a registered target worktree as in the launchpad; a stop of the class `work` still refuses. A gate task whose stop advises is recorded as advised with its output, the tasks after it run and the selection can pass. No refusal names the recovery override as its route, and `npm run features -- list` prints one row for each stop.

**The author's rules are a layer (Part B).** Each of the ten feedback units and 33 shared role rules carries a layer. `"unequip": ["author"]` in an instance's build overlay leaves the author's layer out of the role text, the hooks and the settings; a single id keeps or removes one rule. An instance that names none emits what it emitted before.

**The paraphrase rule's stop has a level (Part C).** In an instance, text carried from what its owner pasted under the intake root is advised of in one line a file and fails nothing.

**A drive that stops says why (Parts D and E).** A host's denial of a helper agent's call no longer ends a phase, a Claude phase's reviewers are not stopped ten minutes after its worker's turn, the drive's record keeps what was denied without keeping what the call was given, and `node scripts/drive.mjs why WO-NNN` prints the account, which the router gives the operator. On the operator's direction during the order, a Claude release-close phase starts with a narrow rule for the close's one helper command, and the Codex workers now ask for GPT-6.2 Sol and GPT-6.2 Astra.

The operator objected that these repairs belonged to a fix dispatch rather than to the final review, and the review records that objection and a stop it made while answering it as corrections ([WO-287-D090](../../evidence/WO-287/decisions.md#wo-287-d090--critical-error-the-final-reviewer-stopped-work-and-waited-for-the-operators-choice-when-the-operator-had-not-said-to-stop), [WO-287-D091](../../evidence/WO-287/decisions.md#wo-287-d091--correction-the-final-review-repaired-the-defects-its-readers-found-instead-of-failing-back-to-a-fix-dispatch-and-spent-the-operators-fable-budget-on-a-third-repair-cycle)).
