An agent working in this repository now receives its session's measured facts before it speaks: the clock, every journaled background dispatch with its last observed state and elapsed time, the duration of each gate row for the current dispatch, and the usage counters with their source, scope and cutoff. Values that were not observed print `unknown` beside a cause code rather than being estimated. The block reaches the briefing, the Claude prompt-submit context and the Stop advisory.

When an estimate marker (`roughly`, `about`, `approximately`, `around`, `probably`, `I think`, `should be`, `~`) still lands next to a number, duration or clock time in a final assistant message, the Stop hook journals the hedge with the observed value when the journal holds one for that quantity and with `unmeasured` when it does not, and the next boundary delivers that measurement once. Quoted text and fenced code are exempt so evidence citations survive intact. Nothing is refused, no turn is held, and re-entry with `stop_hook_active` rescans nothing. This is the shape the operator asked for: the mechanism removes the guess, it does not gate responses.

The process meter's `operatorCorrections` no longer reads decision documents, which is self-report. It now counts journal events — typed `correction:` prompts and the hedges above — and the shifting-the-burden trap row carries them per order, per phase and per explicitly named judgment unit (never guess, `correctness-over-sycophancy`, `anti-oscillation`, `fail-conservative-correction`). A unit is attributed only when it is named, never inferred from tone. This is measurement only; no automatic consequence is attached, and what a later pass does with the rows is that pass's decision.

Codex has no Stop hook. There the briefing and the lifecycle commands print the same block and run the same scan over the thread's already available final messages and their own handoff output; a final answer written after the last lifecycle command is observable only at a later boundary.
