## Release overview

A DotLn session now hands the agent its own measured facts before it answers — the clock, each journaled background dispatch with its state and elapsed time, the duration of every gate row for the current dispatch, and the usage counters with their source and cutoff — so a number that can be measured no longer has to be estimated. When an estimate still slips into a handoff, it is journaled with the observed value and corrected once by advisory that holds no turn. This release is for operators and contributors who rely on handoff numbers being measurements rather than impressions.

## Read before upgrading

The `Stop` hook now always returns a `systemMessage` carrying the observed-facts block, where it previously returned an empty object whenever no completion advisory was pending; it still carries no decision key, never blocks and does not re-enter. The process meter's `operatorCorrections` changes meaning rather than shape: it is derived from journaled typed `correction:` events and journaled hedges instead of from decision documents, so a stored per-order count that was not itself derived from a session journal is not carried forward and reads 0 until journal events exist for that order. Session journals under `docs/control/local/` gain hashed background-task keys, hedge phrases and their observed values; that directory is ignored local state and is neither published nor committed. No refusal, permission boundary, public event schema, authority rule or third-party dependency changes, nothing is removed, and no operator action is required.

## Substantive changes

Observed facts reach three surfaces: the lifecycle briefing, the Claude prompt-submit context and the Stop advisory. Every absent value prints `unknown` beside a cause code — `dispatch-unavailable`, `counter-unavailable`, `no-session-gate-row`, `session-identity-unavailable` — so a missing observation is visible as missing instead of being filled in. Gate rows and usage rows are scoped to the current order and dispatch.

The hedge advisory is lexical and nonblocking. An estimate marker within one clause of a number, duration or clock time in a final assistant message is journaled with the observed quantity when the journal holds one, and with `unmeasured` when it does not; the next boundary states that measurement once and never repeats it. Fenced code, indented code, block quotes, inline code and quoted strings are exempt, so evidence citations and quoted examples are untouched. Stated values and explicit `unknown` journal nothing.

The correction meter counts events, not documents. Typed `correction:` prompts and journaled hedges are counted once each across the configured session and effect hooks in either execution order, and the shifting-the-burden trap row carries the totals per order, per phase and per explicitly named judgment unit: never guess, `correctness-over-sycophancy`, `anti-oscillation` and `fail-conservative-correction`. A unit is attributed only where it is named, never inferred from tone, and the measurement carries no automatic consequence.

Codex, which has no Stop hook, gets the same mechanism through its lifecycle commands: the briefing and each command print the block and scan the thread's already available final messages together with their own handoff output. A final answer written after the last lifecycle command is observable only at a later boundary.

## Progressive polish

The generated harness manifest and hooks are repinned to the new runtime snapshot, the console selfhost fixtures and publication edition locks are regenerated, and the work-order index, control projections, decisions index, idea ledger and follow-up register reflect the completed order. New authority and feedback revision-001 evidence editions record the changed runtime bindings; earlier editions remain intact. Three stale fixture assertions in the process-debt suite were repaired to distinguish observational presence hooks from governance hooks, retaining every governance assertion; the change is test-only and is recorded in D002.

Known limitations, all of which fail to `unknown` rather than to an invented value: a background shell task is not journaled at dispatch, so only agent dispatches carry a measured dispatch time and elapsed value; the Codex half of the mechanism rests on fixtures, because no Codex session was available to the verifier or the reviewer; an estimate marker set off by commas escapes the clause scope, so the counter under-counts rather than misattributing; untyped operator corrections and unmarked guesses stay outside the count; and in Claude the briefing still prints a `session-identity-unavailable` line shortly before the real block. This is lexical measurement, not semantic truth checking. The gate runs outside a nested OS sandbox, in which the unrelated discovery and resident suites cannot launch their own probes.
