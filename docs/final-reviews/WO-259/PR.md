# :lock: The operator's words stay out of committed text: the document gate and the publish helpers screen what a branch adds against the ignored captures and the private terms list, review workers never print the local lane or an author line, and a record filed into a target links to a launchpad commit that holds its destinations

The standing rule of 2026-11-07 is that no operator message is saved verbatim in a committed artifact; until now only the role text and the reviewer carried it, so a verbatim copy with no attribution passed every gate, and the private instance's first cycle found chat words copied into decisions, discovery files and generated pages. This change gives the rule its enforcement in the kit: every role root in both skill roots and all three worker definitions carry the paraphrase rule and two no-print rules ([D003](../../evidence/WO-259/decisions.md#wo-259-d003)), and `npm run test:docs` holds a branch to it against its merge base with `main`, so a record written before keeps its bytes ([D006](../../evidence/WO-259/decisions.md#wo-259-d006)).

The document check's verbatim screen compares every line a branch adds to Markdown under a document root or at the repository root, or to source under `scripts/` and `packages/*/src/`, with every text capture under this checkout's ignored intake root; a run of twelve consecutive normalized words both hold fails naming the file, the line and the capture's digest, never the words. A run the repository already held at the merge base is its own text, a checkout with no capture prints `verbatim screen: no captures` and passes, and a closed private entry below the intake root is named in an advisory ([D020](../../evidence/WO-259/decisions.md#wo-259-d020)). The window is measured, not guessed: over the lines the last six merges added against this repository's 540 captures, the runs not already in the repository were 66 at eight words, 27 at ten and 15 at twelve, the twelve-word ones being technical passages carried from pasted blocks. A record the branch adds that attributes words to the operator without a capture citation fails too, where before it advised. The exception is typed: an `operatorQuote` the branch adds carries `captureSha256` and `requestedIn`, the digest of the capture holding the operator's request to save that message, and the screen exempts that capture's words inside the quotation alone. An instance that elects `features.verbatim-operator-words` turns the rule off, and both checks then advise ([D005](../../evidence/WO-259/decisions.md#wo-259-d005)); this repository elects nothing.

The private local-terms list now screens what a branch publishes, not only what the export writes: the document selection gains a `terms` task over the lines a branch adds (on `main`, what the last merge brought in), failing by file, line and mode without the term and advising `local-terms list: unavailable` where no list is registered, and the planning, kit-update and order-branch publish helpers screen the branch's committed change the same way before the first push; a malformed list refuses naming its line, never a term ([D009](../../evidence/WO-259/decisions.md#wo-259-d009)). The launchpad publish form refuses an order whose committed control record shows no passing final review, naming the phase it read ([D010](../../evidence/WO-259/decisions.md#wo-259-d010)).

A background worker's hand-back, which the host queues in the same prompt mode as the operator's own messages, is journaled by its envelope with source `host-agent-handback` and attribution `host`; `npm run plan -- check` refuses a standing rule that cites such a row, and `plan failures` counts it apart from the interventions, as it counts the host's task notification ([D008](../../evidence/WO-259/decisions.md#wo-259-d008)). The canonical review brief carries the three rules through the worker definition it embeds, so no launching session writes them by hand ([D004](../../evidence/WO-259/decisions.md#wo-259-d004)). Discovery names a record it cannot parse on the attestation and in status, apart from a missing observation, and records each version and version line once, saying `already recorded` on a rerun ([D011](../../evidence/WO-259/decisions.md#wo-259-d011)).
