**O2 (VER-001 O2) — the live smoke client can label a deadline as a cancellation. Reproduced.** `main()` in `local-runner-smoke.mjs` observes runner state with `execFileSync`, which blocks the event loop, so the deadline timer cannot fire during the observation. On a loopback double with a 40 ms deadline and a 100 ms observer, a blocking observer produced `cancelled` with the abort at 131 ms and an asynchronous observer produced `timeout` at 42 ms. D003's claim that "timeout overwritten by cancellation" was corrected therefore holds for asynchronous observers and not on the smoke client's own live path. No recorded row is affected: the live deadline was 30,000 ms, the observer is capped at 2,000 ms and the first delta arrived at 730.75 ms. The mislabelled case would still be a real mid-generation cancellation; what it would lose is the fact that the deadline had passed.

**O3 (new) — without an idle observer, the load client labels its own traffic deadline as a request failure. Reproduced.** The final request's deadline is the remaining traffic budget, so its timer and the run's `duration-limit` timer expire within a millisecond of each other, and the request's usually fires first. `runLoad` then sees a non-completed row while its controller is not yet aborted and records `request-failure`. Over 20 runs on a loopback double with no `observeState`, 17 stopped as `request-failure` and 3 as `duration-limit`; with an asynchronous idle observer, which the live entry always supplies, all 20 stopped as `duration-limit`, because the idle wait lets the deadline timer fire before the check. The recorded live run is of the second kind and its label is right. Either way the run stops, so the direction is conservative; the defect is that an expected two-minute limit can be reported as the "unexpected request failure" stop condition. Product 07 §Research rule 4 routes any promotion of these clients through a separate implementation order; that order should use an asynchronous observer in the smoke client and decide the stop reason from the deadline, not from timer order.
