## Release overview

DotLn `v0.5.0` is the first minor above the published `v0.4.1`. It adds the platform's second founding identity as compiled instance content: the Entropy Reducer, a whole-repository planning reviewer, is authored as typed data, compiled through the pure composition compiler into a bounded WorkOrder and authority envelope, and projected into a generated review residue that a hand edit cannot survive. Its output is held by typed validators before any report leaves the episode, and the release carries the evidence of its first use: one operator-mediated review episode under the pinned Claude Fable 5.1 `max` actor, followed by a fresh blinded refutation in which all seven findings survived. To lower that loadout the compiler gains one bounded capability, direct terminal prefix globs in authority compositions that carry no participating authority claim. Audience: the operator dispatching review episodes, any session that runs as the Entropy Reducer, and consumers of the compiler contract. This release carries `@dotln/compiler` `0.2.0` and `@dotln/skeleton` `0.5.0`; `@dotln/kernel` `0.2.1` is unchanged. No model transport is added: the kernel's `Program.All` remains deferred, so the review Program is followed by hand, and the executable scenario's executor and verifier remain deterministic fakes.

## Read before upgrading

- **The compiler accepts patterns it used to refuse.** A direct terminal prefix glob such as `repo.read*` in an active's WorkOrder operation lists, its AuthorityEnvelope effect lists, or a linked support's permission-guard emission now compiles when no linked support carries an `authority.*` claim; compiler `0.1.0` refused every wildcard with `SEMANTICS UNSUPPORTED`. A graph that combines a direct wildcard with a participating authority claim still refuses, with the diagnostic now reading that the compiler cannot combine the wildcard pattern with linked authority claims; a wildcard claim target on a linked support still refuses with its unchanged diagnostic; unequipped catalog definitions remain inert. A caller that relied on the blanket refusal, or matched the old diagnostic text, must adjust. A bare `*` also compiles in a claim-free graph, and under the kernel's prefix matching it grants every effect; the compiler does not refuse it, so do not author one.
- **Component versions and pins.** `@dotln/skeleton` `0.5.0` depends exactly on `@dotln/compiler` `0.2.0` and `@dotln/kernel` `0.2.1`. The compiler minor reflects widened accepted input, not a changed contract version: `CompiledProgram.compilerVersion` stays `"1"`, and existing Seiri hashes are unchanged.
- **`docs/instance/` is a new tracked root with a generated file.** `docs/instance/entropy-reducer/RESIDUE.md` is rendered from the loadout definitions, and `npm test` byte-compares it with a fresh render. Editing the file by hand fails the suite; change the definitions and regenerate instead. The refutation plan and the run records beside it are reviewed evidence, not templates.
- **Application versions above `v0.5.0` are unassigned.** WO-023 took `v0.5.0`, so the roadmap's former `v0.5.0` through `v0.10.0` targets for WO-009, WO-010, WO-011, the projections console, the pattern workshop, and the source-to-deliverable vertical are superseded planning history; each rung receives its version at its own activation, and the five open drafts that cited those versions now cite rung names. ADR-0002 carries the dated amendment. Published tags and the accepted build order do not move.
- **The application-thesis heading changed.** `docs/product/11-proteino.md` now opens with `προτείνω (protíno)`, the Modern Greek verb form with its pronunciation guide; the heading anchor changed, the publication index row and both audience-edition locks were refreshed, and any external link to the old anchor breaks. The file path is unchanged and is not the canonical Latin display form or a technical slug.
- **The compiled reviewer is a manual plan, not a service.** The Program contains an `All` node the kernel does not yet evaluate, so a review episode is dispatched by the operator, its invocation ids are symbolic, and its returned payload is bound by the host validator; each delegated or probe operation must be authorized separately while threading the returned resource envelope, because a numeric maximum inside an intent payload is not kernel enforcement.

## Substantive changes

- **Instance content: the Entropy Reducer loadout.** `packages/skeleton/src/loadouts/entropy-reducer.ts` defines identity `entropy-reducer@1` (verify-first, measure rather than assume, candid and fair, propose rather than mutate, shape-first on operator analogies; invariants including a read-only tracked repository and control plane, a reproduction on every finding, the unweakenable clean-room floor, and settled decisions not relitigated), role `planning-reviewer@1` (census, ladder assessment, non-authoritative suggestions; constraint-first ordering), the Seisō Shine active tagged observe, research, plan, verify, delegate, and narrate and never mutate or destructive, eight linked supports (Seiketsu Standardize, Verify-First, Fan-Out Lens, Mutation Drill, Shape-First, Constraint-First Ordering, Altitude Tag, Sparse Receipt) each declaring tags, semantics, authority change, evidence requirement, cost, and determinism, four masks with named failure modes and guards, and the `auth_entropy_reducer` envelope allowing `repo.read*`, `probe.run:scratch*`, `intake.capture`, `delegate.readonly`, and `report.emit`, denying `repo.write*`, `git.mutate*`, `remote.*`, `settings.*`, and `decision.edit`, with `delegates` 4, `probes` 32, expiry at episode end, and revocation on `OperatorStopRequested`.
- **Compilation and the review Program.** `compileReviewerWorkOrder` compiles the loadout through `@dotln/compiler` and returns the thirteen-field WorkOrder whose operation lists equal the envelope's effect lists and whose `requiredEvidence` is `["reproduction"]`, the envelope, the semantic hash, the exact compile inputs, a `Sequence` Program (census `Invoke`, `All` over four lens `Invoke`s, probe `Invoke`, two readiness `Emit`s, `Await OperatorDisposition` with a once timeout), `Cadence.Once`, the masks, the pinned reviewer requirement (`claude-code`, `claude-fable-5-1`, `max`; a substitute is a different attested reviewer), the execution boundary, the validated lens briefs, and the residue.
- **Typed output and lens-brief validation.** `prepareReportEmit` validates a finding's evidence label against its reproduction kind (a measured finding carries a command, a by-inspection finding carries steps), the altitude range, one-off or recurring standardization with a test, lint, guard, or script rung, unique finding ids, proposal packets with a safe single-segment suggestion id and a `docs/proposals/` path whose final segment is that id path that matches it, an episode-matching result envelope whose summary is under 200 words, and a passing clean-room result, and only then constructs the `report.emit` intent. `validateLensBriefs` requires lens id, files, questions, output shape, a positive integer word budget, and `noFix: true`, refuses extra fields, duplicate ids, intake-bearing and unsafe scopes, and more briefs than the compiled delegate ceiling.
- **Generated residue.** `renderEntropyReducerResidue` projects the identity, role, and active stance, the masks, and one paragraph per linked support in link order with an FNV-1a digest of every emission, followed by the reading order, the clean-room floor, the execution boundary, and the output contract; `referenceEntropyReducerResidue` is the tracked file's oracle.
- **Refutation selection and report.** `selectFindingsForRefutation` selects every measured finding and every by-inspection finding when there are six or fewer, otherwise a deterministic surface-and-severity round-robin sample of `max(6, ceil(n/3))`, and reports a zero denominator as `not-applicable`; `buildRefutationReport` refuses missing, extra, duplicate, or bogus attempts, keeps refuted and blocked findings attributable, promotes only survivors, and applies no quota. `docs/instance/entropy-reducer/REFUTATION-PLAN.md` states the blinding and the rule in prose.
- **Evidence of the first use.** `runs/REVIEW-001.json` and `REVIEW-001-COMPILED-PROGRAM.json` record the pre-repair review episode with its attestation, compile inputs, preserved compiled program at `fnv1a64:b81d0609ee2e9fed`, seven findings, one unfiled proposal payload, byte-identical status digests, and the confinement inventory; `runs/REFUTATION-001.md` and `.json` record the blinded episode, its selection, and the seven survivals; the implementation repaired every finding before requesting verification, and the repaired subject compiles at the same inputs to `fnv1a64:eefe230707d23735`.
- **Compiler: claim-free prefix-glob lowering.** `compileLoadout` computes the linked `authority.*` claims and refuses a direct wildcard in the active's operation or effect lists or a linked permission-guard emission only when such a claim participates; wildcard claim targets on linked supports refuse unconditionally; unlinked definitions stay inert. Fixtures cover active-origin and support-origin grants and denials, the inert case, wildcard-claim refusal, and mixed refusal.
- **Product documentation.** The pattern library names the Entropy Reducer as the second founding identity carrying Shine linked to Standardize; the playbook's actor table gains its row; the architecture records the first live use and the bootstrap exception under which WO-029 reached `docs/work-orders/` directly, adds the candidate pinned artifact identity, and adds the candidate source-addressed context projections; the domain model and interface contract state the compiler's wildcard rule; the ledger adds four dated sections; the roadmap carries the retiming note and the `v0.5.0` rung; the application thesis records the verb, the pronunciation guide, and the related noun; the docs map lists `docs/instance/`.
