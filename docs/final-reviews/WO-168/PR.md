# WO-168

Every role dispatch told the session to use a DotLn scratch path that nothing created. WO-166's final review redirected its first gate log there, the redirect failed, `npm test` never started and the trailing command reported exit 0. While a gate ran, a verifier or reviewer was refused ordinary reads such as `git --no-pager diff HEAD~1`, a quoted angle-bracket pattern such as `grep -n '<…>' f`, `wc -l < a.md` and `ls docs 2>/dev/null`. Four standing sentences understated what WO-166 shipped for the Codex writer.

This pull request lands WO-168. A printed scratch path now exists when it is printed, a scratch grant holds only for a real directory the session owns, a refused Codex dispatch leaves the worktree as it found it, and a live gate admits four argument forms of the reads it already lists while expansion, unquoted globs and other redirects stay refused.

- **The session scratch directory is created where its path is printed.** The Claude role dispatch, the Codex session begin and `node scripts/harness.mjs scratch` create the session's scratch directory under the system temporary directory at mode 0700 first. An existing real directory the session owns is used as it is. A file, a link or an error is one advisory, and the dispatch proceeds.
- **A granted session root is a real directory.** For session-scratch and host-scratchpad grants, a root whose final component is a link, a non-directory or another user's directory grants nothing, and the refusal names the root and the cause. An absent root and the system temporary grant are judged as before.
- **Four argument forms of listed reads pass a live gate.** They are a quoted word holding `<` or `>`, a Git revision suffix (`~`, `^`, `@{…}`) in an unquoted operand, an input redirect from a literal path, and an output redirect to exactly `/dev/null`, plus `npm run --silent resume -- status`. Helper forms compare argument by argument. A listed Git read is also refused while a `%G` pretty format or a `post-index-change` hook is configured. The list names the same programs, and the refusal text states the admitted forms.
- **A refused Codex dispatch releases the reservation it placed**, whatever refuses it before its event is recorded. A reservation the session already held, or one held by another session, is never released. A built runtime that lacks the reservation entry point refuses before any event and names `node scripts/bootstrap.mjs`.
- **An override exit prints ahead of an input refusal**, and a record that was appended is never reported as not appended.
- **The standing text says what ships.** The generated five-refusals sentence states that a Codex lifecycle dispatch reserves the writer and refuses a foreign holder. Product 02 names the refusal's fields and the `codex-host` and `thread` owners. Product 07 names every completion that releases and the main-session release-close route. A hedged gate duration now resolves to the gate identity that contains the one it names, and the destination-adapter comment sits above `shellWriteTargets`.

**What a reviewer should know.**

- **The tokenizer now splits words only on space and tab.** The old split on any whitespace let `cat a`, a non-breaking space and `#;touch x` read as one listed command while every shell runs the `touch`. zsh's `$=`, `$^`, `$~` and `$+` parameter forms and its `=cmd` word now count as expansions. A command word after an `&>` operand makes the invocation opaque, because dash runs those words as a command of its own. These rules can only refuse more ([D012](../../evidence/WO-168/decisions.md#wo-168-d012--review-dispositions-and-two-adjacent-repairs), [D015](../../evidence/WO-168/decisions.md#wo-168-d015--repair-of-ver-001-f1-and-f2--followed-by-words-and-zshs--word)).
- **One advisory edge is boarded, not fixed** ([D018](../../evidence/WO-168/decisions.md#wo-168-d018--final-review-pass-and-board-one-hedge-edge-and-two-fixture-observations)). A hedge phrase that names both `npm test` and `npm test -- --inside-sandbox` on their own now resolves to the partial run's duration, where it was unmeasured before. D018 also records that the fixtures' private temporary root no longer reaches a session root through macOS's `/var` link.
- **Recorded limits stay recorded.** Only a session root's final component is inspected, so a swapped ancestor still carries the grant ([D004](../../evidence/WO-168/decisions.md#wo-168-d004--item-2-a-granted-session-root-is-a-real-directory)). Which shell each supported host runs tool commands through is not established ([D006](../../evidence/WO-168/decisions.md#wo-168-d006--item-4-four-argument-forms-one-spelling-two-git-conditions)).
