## Release overview

A role session can now use the scratch directory it is told to use, and keep its ordinary reads while a test gate runs. The harness creates the printed session scratch path before printing it, grants a scratch root only when it is a real directory the session owns, and admits four argument forms of the read-only commands a live gate already lists. A refused Codex dispatch no longer leaves its writer reservation behind, and the standing text describes the Codex writer boundary WO-166 shipped.

## Read before upgrading

No action is required. Beside a live `npm test` gate, `git --no-pager diff HEAD~1`, a quoted `<` or `>` in a listed read, `wc -l < file`, a `2>/dev/null` sink and `npm run --silent resume -- status` are now admitted. Some commands that were admitted before are now refused. A word that holds a non-breaking space or another blank other than space and tab stays one word. zsh's `=cmd` word and its `$=`, `$^`, `$~` and `$+` parameter forms count as expansions. A command word after an `&>` operand makes the invocation opaque. A listed Git read is refused while the repository configures a `%G` pretty format or a `post-index-change` hook. A session-scratch or host-scratchpad root that is a symlink, not a directory or another user's directory grants nothing, and the refusal names it. The system temporary grant is unchanged. On a temporary directory shared by several users, a second user's scratch creation under the shared `dotln` directory there can fail; that is one advisory and never blocks a dispatch.

## Substantive changes

The Claude role dispatch, the Codex session begin and `node scripts/harness.mjs scratch` create the session's scratch directory under the system temporary directory, at mode 0700, before printing or returning its path. An existing real directory the session owns keeps its mode and contents, and a file, a link or an error is one advisory. The outside-write guard inspects the final component of a session-scratch or host-scratchpad root before granting under it. An absent root is judged as before, and an inspection failure other than absence keeps the guard's single advisory and admission. The live-gate list keeps its programs and admits a quoted word holding `<` or `>`, a revision suffix (`~`, `^`, `@{…}`) in an unquoted operand of a listed Git read, an input redirect from a literal path, an output redirect to exactly `/dev/null`, and `--silent` on either side of `resume`. Helper commands are compared argument by argument. A Codex dispatch refused after placing its reservation, for any reason before its event is recorded, releases that reservation and never releases one it did not place. A built runtime without the reservation entry point refuses before any event and names `node scripts/bootstrap.mjs`. With an operator override exit pending, the exit message and record command print ahead of a hook-input refusal. Whether the override record was appended is read from the order's log.

## Progressive polish

The generated five-refusals sentence, product 02's writer paragraph and product 07's index paragraph and release-close row now state the Codex dispatch reservation, the refusal's fields and owners, every completion that releases the writer, and the main-session release-close route. Product 07 names the admitted forms, the scratch creation and the granted-root rule. A hedged gate duration resolves to the gate identity that contains the one it names, and one misplaced source comment moved to the function it describes. A writer-refusal fixture that compared two processes' clocks now ignores only the age field.
