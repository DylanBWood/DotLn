# The kit guide is rewritten so its readers can follow it, with no fact lost, and later write-backs are held to the same standard

The kit guide, `docs/KIT.md`, is rewritten section by section. Each section says first what it is for, a procedure is numbered steps, rules are lists, options are lists or tables, commands are blocks, and the decisions behind a passage are linked on one line at the end of its subsection. The guide opens with a table that leads from a task to its section. The 761-word paragraph on publishing a target order's change, which the order names as the first passage to rewrite, is now [a subsection](../../KIT.md#publish-a-target-orders-change) of four numbered steps, a table of the publish's three checks and short lists. The earlier guide held 63 paragraphs over 120 words, the longest 1,452; the rewritten one holds none, and its longest is 111. This is [WO-281](../../work-orders/WO-281-the-kit-guide-is-easy-to-follow.md), planned as the minor `v1.1.0`.

**What holds a later write-back to this.** Two things, and neither is a refusal. The document gate now lists, by file and line, each paragraph over 120 words that a branch adds or changes in a standing document, for the stage at hand to read and, where it is hard to follow, rewrite; `node scripts/docs-check.mjs --long-paragraphs` prints the same reading of every standing document. The figure is `documents.paragraphWords` in `docs/control/budgets.json`, 120 when unset and `null` for no list, and a value the check cannot use stops no command ([D010](../../evidence/WO-281/decisions.md#wo-281-d010--step-4-the-document-check-lists-the-long-paragraphs-a-branch-writes-in-standing-documents-at-a-figure-of-120-words-and-prints-the-whole-list-on-request)). The rule every role carries now has the final reviewer return to repair a changed standing passage its reader cannot follow, naming it, and product 07 says the same ([D011](../../evidence/WO-281/decisions.md#wo-281-d011--step-5-the-final-reviewer-returns-a-changed-standing-passage-its-reader-cannot-follow-in-the-rule-every-role-carries-and-in-product-07)).

**The documentation map.** The `docs/README.md` that every instance carries is rewritten the same way, as three pointers and a table of the roots, and its text is now a kit template. A starter refresh brings a starter's map to the current one where it still holds the bytes an export wrote, and keeps one its owner changed, with the reason ([D012](../../evidence/WO-281/decisions.md#wo-281-d012--step-3-the-documentation-map-is-a-kit-template-rewritten-as-a-table-of-the-roots-and-a-starter-refresh-brings-a-copy-an-older-export-wrote-to-it-and-keeps-one-its-owner-changed)).

**No fact left the guide.** The order's inventory finds every heading, command-block line and link target of the earlier guide in the rewritten one. Three code spans are absent, each because it was renamed to its whole command, and each is recorded with its reason ([D022](../../evidence/WO-281/decisions.md#wo-281-d022--round-ones-fixes-as-built-the-rule-table-regenerated-a-case-for-criterion-3-no-refusal-over-the-figure-the-cases-the-reviewers-found-missing-and-the-guide-and-the-map-changed-where-a-reader-was-stopped-or-the-text-read-as-filler)). Of the 1,017 sentences of the earlier guide's prose, the content words of 924 stand together in the rewritten text.
