# WO-157

Six orders closed on 2026-09-22 each left defects boarded up as follow-ups: an integrate helper that stranded a reviewer behind an operator recovery, an adjacent-queue advisory that recurred on every later order, a source-change host that counted nothing and let a writer delete files, a target publication that ran the target's own hooks with the operator's credentials, a skeleton that refused every grant-bearing identity, a resident binding nobody checked against its registered profile, refused live verifier episodes that recorded no cause, receipts that claimed more than their witnesses observed, Claude Code attestations that wrote `unknown` for a supplied effort, evidence registries that stayed green while a protocol moved, an allocation fold that would break on a section-list change, and a gate teardown that failed with no owner. The operator directed that all of them be fixed in one order, once, and this pull request lands that order: fifteen items in six seam groups, each with a fixture that fails against the base commit on its own assertion and passes after, plus a sixteenth item the operator added during repair.

**Closeout machinery.** `npm run worktree -- integrate` refuses an intent-to-add entry before it fetches, checkpoints or writes a receipt, naming each path and the `git add` remedy, and again at `--continue`; a stash push that fails with nothing stashed removes or restores the receipt so a fresh run proceeds, a stash Git stores and then fails to finish resumes with `--continue`, and only a stash entry carrying this integration's name and base counts as its own. The adjacent queue gains a `retarget` action, admitted at final review for a reviewer actor, that moves a deferred item's target onto an existing public `FUP-` identifier and nothing else; the executor's Follow-up Queue rule now says to sync the register before disposing.

**Hosts and the skeleton.** The source-change host reads `git diff --name-status` on the writer's commit, refuses a change over the envelope's `files` ceiling, and refuses any removal or type change without `repo.delete` except the declared Sort move, naming the paths and the ceiling in both refusals. Target publication pushes the observed commit from a host-created bare repository with hooks and fsmonitor off, to origin's configured URL checked against the repository `gh` resolved, so the target's hooks and its push-time configuration do not run in the operator's process; a writer-profile probe is filed with its limits. `isCompilationEnvironment` admits the optional `authorityGrantRegistry`, validated by the compiler's normalizer, so a grant-bearing identity equips and reaches the source-change host while a malformed registry still refuses.

**The resident's binding.** `resident-bind` gains a portfolio form (`--portfolio`, `--template` and `--base`) that builds a portfolio binding from the loaded entry and compiles it under the bound repository's registered `authorityProfile`; `--check` refuses a hand-written store that departs from that profile, naming each departure, or whose profile cannot be read. `--model` and `--effort` are optional: `codex-cli-exec` defaults to `gpt-6-luna` and `claude-cli-print` to `claude-sonnet-5`, both at `xhigh`, and the binding records whether each value was a default or the operator's choice.

**Live episodes and receipts.** An `invalid-result` refusal now carries a typed detail from a closed vocabulary into the `WorkerInterrupted` event and the `dotln` line (`worker refused: invalid-result (finding shape); pending work is retained`); raw model output still never reaches the store. The Entropy Reducer's witness records the source repository's untracked listing and the frozen copy's added, removed and resized paths, hashed with NUL framing so two different path lists never read as identical, and its sentence names only what it observes; a refutation receipt renders each attempt's typed reasons instead of a pasted statement. Claude Code exports its selected effort as `CLAUDE_EFFORT`, and a claude-code lifecycle attestation under a readable value must be exactly that effort from `claude-session-readback`; any other effort or source, `unknown` included, is refused before an event is appended. The verifier's output schema now states admission's finding rules, so a subject with no failing witness admits no finding and no `fail` verdict; the re-mint's live episode ran under it and completed on its first attempt.

**Registries, the fold and the gate.** Each evidence edition's `--check` reads every registered source's imports from TypeScript's own scanner tokens and refuses an unregistered, unexcluded runtime sibling; the two protocol files are registered and in the feedback subject, so moving one stales the edition. A `registrations` document-gate row asserts that every committed or untracked JSONL under `docs/` is an `EventEnvelope` stream or classified in the kernel's registry, and that every document-gate script has a stub. `WorkOrderIdentityAllocated` records the digest of the section set it was written under, the fold validates against that set, and a corrupt authority makes only its own order unreadable. The gate-sandbox fixture disables Git's automatic maintenance before its first commit, which is the detached repack that raced its teardown (172 of 200 `ENOTEMPTY` before, 0 of 200 after), and each gate tags its roots and fails naming any that survive.

**Two verifications and one review.** [VER-001](docs/verifications/WO-157/VER-001.md) failed on four findings: the file-to-directory refusal omitted its ceiling, the untracked listing's newline join could collide, a same-session effort mismatch was admitted as an advisory, and the import regex missed legal forms; the repair ([D031](docs/evidence/WO-157/decisions.md#wo-157-d031) to [D034](docs/evidence/WO-157/decisions.md#wo-157-d034)) fixed each, the operator's scope expansion ([D030](docs/evidence/WO-157/decisions.md#wo-157-d030)) brought the verifier schema in as item 16, and every edition was re-minted once more with a new live episode. [VER-002](docs/verifications/WO-157/VER-002.md) reproduced each finding against the repair and passed all twenty criteria. [FINAL-001](docs/final-reviews/WO-157/FINAL-001.md) passes and boards up three residuals it found and reproduced: the publication's commit-message read in the target root still honours a repository-level `log.showSignature` and `gpg.program` a writer-controlled test could plant, and the push-URL check does not catch a direct edit of `remote.origin.url` ([D038](docs/evidence/WO-157/decisions.md#wo-157-d038), due before WO-066's first target publication); a kill between a successful stash push and the receipt save lets `--continue` finish without re-applying the retained stash ([D039](docs/evidence/WO-157/decisions.md#wo-157-d039)); and `resident-bind --check` never compares the record's `profileId` with the profile it checks under ([D040](docs/evidence/WO-157/decisions.md#wo-157-d040)).

**What a reviewer should know.** A source-change writer that removes a path is now refused unless the removal is a declared Sort move; a target whose push relied on repository-level configuration (a scoped credential helper, a URL rewrite, an operator's pre-push check) no longer gets it during DotLn publication, while global and system configuration still apply; a refutation receipt records no worker statement; and a Claude Code completion that attests `unknown` or another source under a readable `CLAUDE_EFFORT` is refused. The source-change host still runs the order's test command with the operator's privileges and no OS sandbox, which is why writer-controlled test code can reach the target's common Git directory; that containment is deferred by the operator's authorization as adjacent-0001 (`FUP-92fd86e53b44fa39`), due before WO-066. Whether Codex's structured-output mode accepts the tightened verifier schema is not established; no live writer episode was run for the publication guard; whether a nested `claude -p` inherits `CLAUDE_EFFORT` is unprobed; and the feedback subject follows only the two named protocols, not the whole import graph ([D013](docs/evidence/WO-157/decisions.md#wo-157-d013)).

VER-002's independent product gate passed 27 suites at the same source, and the executor's post-repair review gate passed 41. `git diff --check` is clean, no dependency is added, and `plan check`, `publication:check`, `harness check` (31 surfaces), `harness-context --check`, `check-registrations` (317 streams, 21 stubs), every edition `--check` and `release check-surfaces --local` (44 PASS) pass. The review reproduced its own findings in scratch before recording them. Implementation and repair ran on Claude Code 2.1.280 / `claude-opus-5-5[1m]` at `xhigh`; both verifications ran on Codex CLI / `gpt-6-sol` at `xhigh` with session readback; the review ran on Claude Code 2.1.281 / `claude-fable-5-1` at `xhigh` from the host's `CLAUDE_EFFORT` readback.
