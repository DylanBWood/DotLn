The probe record shows writer-controlled test code can write that configuration, so a planted program would run with the operator's privileges after every refusal and before the lane push. The same review found the push-URL cross-check catches a rewrite but not a direct edit of `remote.origin.url` to another pushable repository, a WO-064 exposure. Outside criterion 1's stated cases and not a regression; D002's "every crash point recoverable" is narrowed.
