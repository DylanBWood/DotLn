# WO-045 — Refuse malformed event logs and hook input with a typed path before anything runs

The two boundaries every governed session and every worker cross first now decode positively instead of casting. The kernel's `tryDecodeLog` validates each JSONL line against EventEnvelope schema 1: a closed key set, `schemaVersion: 1`, `evt_N` identity equal to the physical line number, string `type`, `actorId` and `workstreamId`, a finite numeric `occurredAt`, optional string `episodeId`, `correlationId` and `causationId`, and any JSON payload walked iteratively so overflow refuses and depth cannot exhaust the stack. A failure is `{ ok: false, code, path, message }` whose message keeps the historical `Malformed JSONL at line N:` prefix and names the code and JSON path; `decodeLog` throws that message for existing callers and `appendEvent` refuses to extend a log that no longer decodes. The skeleton's `decodeHarnessInput` validates the declared hook fields and the configured event, refuses inherited and accessor properties without evaluating them, keeps unconsumed native metadata, and answers invalid JSON or a malformed field with the event's own protocol response: PreToolUse denies, UserPromptSubmit accepts with a diagnostic, PostToolUse and Stop report. The compiler's generated entry now hands the raw stdin text to that decoder and runs the independent recovery prelude only for a plain object that carries a string session or a recovery phrase, so malformed input can no longer be handled or dropped ahead of the decoder while `analysis:` and `operator override:` stay reachable without a usable session or a healthy runtime.

What is proven: a committed corpus of 22 malformed lines refuses with 22 distinct code/path pairs at physical line 1 and again at line 2 behind a valid line, with `decodeLog` and `appendEvent` throwing the identical message; all 66 committed EventEnvelope streams (3,968 events) decode and re-encode byte-identically with 39 files of other JSONL protocols listed explicitly and any unlisted `.jsonl` decoded strictly; the WO-003 frozen oracle hash and the WO-101 corpora are unchanged; the skeleton test refuses 28 malformed hook shapes plus getters that are never invoked; ten malformed payloads piped into the generated PreToolUse hook deny with `CODE at PATH` and write no host state; the eleven WO-039 fixtures, the WO-127 stdin shapes and the six WO-131 recovery cases pass over the regenerated bundle, including the case whose `{not-json` payload now reaches the typed refusal instead of the bootstrap fallback.
