## Release overview

A drive typed once now finishes on Codex as it does on Claude, or stops saying why and what to type next. When Codex's automatic review declines the release close, the drive keeps the host's printed reason with the receipt, stops at `awaiting-close`, and names the attended close and the one admitted host change instead of ending at a bare refusal; the reason the review gave, a launchpad handoff sentence that described a no-release close as publishing a tag and a Release, is corrected at its source, and with that correction the review admits the close. Every live receipt names the code identity it ran on, so a requalification claim is a comparison rather than a sentence, and the sandbox a routed run gets is the instance's declared election. This matters to operators who drive orders through the router on either host, to instance owners who decide whether their routed runs are sandboxed, and to maintainers reading receipts, who can now tell which code a run exercised and why a host declined a command.
