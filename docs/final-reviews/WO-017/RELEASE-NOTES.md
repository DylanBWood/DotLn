## Release overview

Four kernel boundaries that used to corrupt, ignore, or decorate now fail loudly and leave a trace, and each one is bound by a test that a targeted mutation breaks. The event-store codec refuses a partial tail, a blank line, a whitespace-only log, or a missing final newline with the physical line number instead of counting, gluing, or renumbering; outbox replay never reports an already-completed command as pending when its result precedes its persist; the authority guard decides the expiry instant, evaluates its refusal rules in a pinned and visible order, evaluates revocation conditions as data through the shared predicate registry, and returns a decision trace for grants as well as refusals; and the evaluable Cadence and Program subsets are exported as data. The walking skeleton now revokes inspection authority through a real predicate condition when the operator returns, records the grant trace in its existing decision slot, and labels its audit evidence honestly. Audience: anyone building on the kernel's store, outbox, or authority contracts, the WO-018 release-manifest consumer of the evaluable-kind data, and the corpus orders that measure these boundaries. This is DotLn `v0.3.5`, a compatible patch above `v0.3.4`, carrying `@dotln/kernel` `0.2.0` and `@dotln/skeleton` `0.3.1`.

## Read before upgrading

- **Malformed logs now refuse instead of decoding.** `decodeLog` and `appendEvent` accept only the empty string or newline-terminated JSON-object lines. A log with an unterminated last line, a blank or whitespace-only line, a non-object line, or a missing final newline previously decoded to something and appended a wrongly numbered event; it now throws `Malformed JSONL at line N` followed by the detail. Repair such a log deliberately before appending to it; the crash-recovery protocol that decides what to do with a real partial tail remains WO-009's.
- **Authority expiry is now exclusive.** An envelope whose `expiresAt` equals the current time is expired; before, that instant was undecided by any test and in practice authorized. A caller that relied on authorizing at the exact expiry instant must set `expiresAt` one tick later.
- **Refusal precedence is pinned and has a new rule.** The guard evaluates named rules first-failing in this order: invalid effect, expiry, `cannot evaluate revocation`, revocation, denial, absence from the allow list, missing evidence, resource exhaustion. `cannot evaluate revocation` is new: a non-empty `revocationConditions` list with a missing `state` or `predicateEnv` input, an unknown registry or version, or a throwing predicate refuses rather than authorizing or throwing.
- **A successful authorization now returns a `trace`.** The authorized branch of `AuthorizationResult` carries a `DecisionTrace` with `reactorId: "authority-guard"` and `branchPath: ["authorized", effect]` naming the intent's effect; record it wherever a grant should be visible to audit. Existing calls stay source-compatible because the new envelope field and the two new context inputs are optional.
- **The walking-skeleton demo log changes at two events.** The seventh event's recorded trace is the authority grant instead of the low-information program trace, and the twelfth event's refusal trace lists the condition inputs it consumed. Event count, order, and types are unchanged; the timeline and glyph scene differ only in the version banner; the audit projection's allowed authority record gains the grant event as evidence and the label `authority-trace-and-command-persisted`.
- **`EVALUABLE_CADENCE_KINDS` and `EVALUABLE_PROGRAM_KINDS` are exact by root kind and shallow by shape.** A listed combinator still throws `is deferred` when it wraps an unlisted child; do not read membership as a promise about nested trees.

## Substantive changes

- **Event store codec.** A well-formed log is `""` or N newline-terminated JSON-object lines; decode and append refuse every other shape with the offending physical line number, and append assigns `evt_N` where N is the well-formed line count plus one. Seven tests pin the partial tail, the blank interior line, the whitespace-only log, the unterminated complete object, non-object values, invalid JSON, and the byte-exact append and round trip of a well-formed log. The domain model's Event store row records the contract.
- **Outbox replay.** A `CommandResult` that precedes its `CommandPersisted` is remembered by `commandId` and completes the command when the persist arrives, with the trace `["result", "preceded-persist"]`; the command is never left pending. `replayOutbox` gains an `{ includeTraces: true }` overload that returns the state with its traces, and the one-argument form returns the same corrected state. The architecture's failure-injection matrix row 1 records the ordering clause.
- **Authority guard.** `now >= expiresAt` expires. The eight-deep ternary is an ordered list of named rules evaluated first-failing, pinned by a precedence matrix over every adjacent pair. `AuthorityEnvelope` gains optional `revocationConditions: readonly PredicateRef[]`, and `authorize` gains optional `state` and `predicateEnv` context inputs; every condition is evaluated against every supplied revocation event through the shipped `predicate()` semantics with the authorization context's `now` as the sole clock, and a prior match cannot mask a later evaluation error. Grants return a trace naming the effect, the canonical time, the envelope, the condition inputs when consumed, and the consumed resource; refusals list the condition inputs only when condition evaluation actually ran.
- **Walking skeleton.** The dead `revocationEventTypes: ["OperatorPresenceChanged:return"]` clause is replaced by a real `operator.return-event` condition; inspection is refused `authority revoked` after operator return in both the live and replay paths, and that revocation trace is compared live-versus-replay without adding a log event. The grant trace is recorded in the existing decision slot after the program decision is asserted to have produced an inspect intent. The audit projection treats an immediately preceding, structurally conforming authority-guard v1 grant trace as evidence for an allowed authority decision, labels it `authority-trace-and-command-persisted`, and falls back to the narrower `authorized-command-persisted` label for logs without one; denied records attach only a conforming refusal trace whose branch matches the refusal reason.
- **Evidence hardening.** `EVALUABLE_CADENCE_KINDS` and `EVALUABLE_PROGRAM_KINDS` are exported as data, with a test that enumerates all fourteen Cadence and eleven Program constructors and proves every listed kind evaluates and every unlisted kind throws `is deferred`. `Sequence([])` steps to `Done`; `Every` refuses `NaN` and both infinities; a binding `Backoff` clamp is pinned to the exact `dueAt`, `rngState`, and trace; `replay` is pinned to promote `policy` and to fall back `rngState` to zero.
- **Product documentation from an operator ideation breakout.** Four candidate sections, each filed at status `vision` and none presented as implemented: an exact phrasebook voice support carrying the operator-authored _Dual Survival_ palette and the _Man, Woman, Wild_ line under recorded direct-filing provenance; an exact operator command vocabulary whose first token is `analysis:`; a minimized incident-reporting pipeline from local logs to an authorized GitHub Issue; and a contributed execution pool for community-run, model-specific work orders returned as pull requests. The ledger records the four entries and the work-order receipt names the unresolved choices.
- **Adjacent orders.** WO-105 records a dated scope split: the physical malformed-line lane is absorbed here, and its retained corpus targets valid-object anomalies and byte-offset sweeps against the landed codec. WO-103 carries a dated compatibility amendment retargeting its oracle to the eight-rule precedence, the exclusive expiry boundary, semantic revocation, and the trace-bearing replay projection.
