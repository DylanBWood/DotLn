# WO-067 — Compile the operator-away curve as phases that widen only as each verifies and never past the base

A loadout graph may now carry an optional `presence` collection, and a build with one declares how its actor behaves while the operator is away. A policy names its four axes (attention, work scope, effect authority, observed external capability), an ordered list of phases, the `progressive` curve, the `cancel-on-return` rule and an idle decay. Each phase declares an entry cadence or condition, an attention priority, a scope (named surfaces, a host-counted file and line ceiling, a budget), an envelope, the external capabilities it needs, whether it is discretionary, and whether an in-flight episode finishes or is killed when the operator returns. The compiler validates every phase envelope against the final compiled base, after grants and claims: an allowed effect must sit inside the base's allow patterns and outside its denials, a resource limit cannot rise above the base or create a positive allowance the base lacks, expiry cannot extend, and denials, required evidence and revocations only accumulate. A phase that would widen refuses with `AUTHORITY WIDENING`; an unknown curve, return rule, cadence kind or field refuses naming its path. What compiles is data: an effective envelope per phase, a gated kernel cadence in the executable subset, cancel predicates, a statechart with `present`, the phases and `expired`, typed guards and actions, and an availability that is `NoOp` with a reason when a required adapter is absent. The compiler emits and never schedules.

The curve is proven as data against the emitted table with the real kernel authorizer and cadence evaluator: nothing dispatches while the operator is present; only a verified success of the current policy episode advances a phase, while an unverified or foreground outcome does not; a failure resets to the first phase; success at the peak resets and the loop repeats; a return in either ordering of the same tick wins, kills the probe episode or lets a widen episode finish without overlapping dispatch, and leaves an explicitly requested foreground task running under its own authority; idle expiry lands exactly at the declared millisecond and needs a recorded return and a fresh absence to rearm; an admitted portfolio grant whose adapter is missing yields a `NoOp` naming the capability. For every phase and five effects, whatever the narrowed envelope authorizes the base authorizes, and each file ceiling is exhausted at exactly its declared count. A graph without the collection compiles to the same bytes and semantic hash as before (`fnv1a64:9ca8d0229c6bd8db` for Seiri with or without an empty collection); a graph with one moves its hash when any phase changes, so a fork's actor behaves the same under the same hash. The code DSL, function table and statechart JSON each round-trip a graph with `presence` to a deep-equal compile, and the tooltip's PULSE and INTERRUPT sections derive the progression, each phase's authority, ceilings, budget, entry, availability, return disposition and idle expiry from compiled values, so authored prose cannot hide a different compiled curve.

The compiler moves to 0.11.0 for application v0.19.0; the skeleton's compiler pin and the lockfile follow, the console self-host fixture is re-recorded against this order's feedback edition, and kernel 0.2.1, skeleton 0.16.0 and console 0.1.6 keep their source versions with no new dependency. The version bump exposed a harness defect the operator directed be repaired here: the runtime snapshot's fingerprint omitted the compiler module whose version the hooks check at admission, so a compiler-only release reused the old snapshot and the regenerated hooks refused their own runtime. `scripts/lib/harness.mjs` now pins that module, a regression bumps only the compiler version, re-emits, asserts a fresh snapshot beside the retained old bytes and then runs the emitted writer hook and requires it to reserve its writer, and the nine hooks and the manifest are regenerated at the new snapshot with the previous one kept on disk.

VER-001 passed every criterion and the repair with no findings: a fresh product gate, the harness test file, twenty-four hostile compile probes, and a mutation run on a scratch mirror that killed nine of nine deliberate breaks of the lowering. The final review re-read the whole subject at source, ran the generated-surface, publication, format, authority and whitespace checks, probed that presence enters the semantic hash, confirmed the fixture's probe → widen → peak → reset reading against the order and the planning receipt without editing it, and ran the single reviewer gate `npm test -- --review`; its row is recorded in the final-review event and carried below. See `docs/final-reviews/WO-067/FINAL-001.md`, `docs/verifications/WO-067/VER-001.md` and `docs/evidence/WO-067/decisions.md`.

Read before merging: the fixture host is a bounded interpreter of emitted data, not the resident runtime; WO-068 must select a policy, register the three emitted predicate identifiers, enforce current presence and capability, count actual files and lines, spend budgets, correlate episode outcomes and execute return dispositions. A phase's `scope.changeSize` and `budget` are host-counted policy data and are not compared with its effective envelope, so WO-068 decides which ceiling wins when they disagree; `expired` is left only by a recorded return, so a run that went quiet should be visible in status; a non-discretionary phase leaves on return without a kill or finish and no fixture exercises one; compile-time availability is a snapshot the host rechecks before dispatch. The fixture policy is data the operator may edit before activation. The executor's attestation recorded model and effort `unknown` under Codex CLI 0.154.0; the contract logs and never refuses, and the verifier and reviewer read every output the executor's completion advised on.
