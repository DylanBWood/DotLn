## Release overview

DotLn v0.19.0 lets a build declare how its actor behaves while the operator is away. A loadout graph may carry an optional `presence` collection whose policies name four axes, an ordered list of phases, a progressive curve, cancel-on-return and an idle decay. The compiler validates every phase's envelope against the final compiled base and refuses any widening, lowers each phase to an effective envelope, a gated kernel cadence, cancel predicates, a statechart gate and an observed capability availability, and renders the curve in the tooltip from compiled values. The seven fixture behaviours run against the emitted table with the real kernel authorizer and cadence evaluator: hold while present, advance only on verified success, reset on failure and at the peak, return that kills or finishes discretionary work while a requested foreground task continues, exact idle expiry, and a reasoned `NoOp` for a missing adapter. Programs without the collection keep their exact bytes and semantic hash. The compiler emits; resident scheduling is WO-068.

## Read before upgrading

Source release target v0.19.0 includes compiler 0.11.0. Kernel 0.2.1, skeleton 0.16.0, console 0.1.6 and third-party dependencies are unchanged; the lockfile diff is the compiler version and the skeleton's pin to it. No package distribution or hosted service is introduced.

The collection is optional and additive under loadout schema 1 and compiled-program contract 1. A graph without it, or with an empty list, normalizes and compiles to the same bytes as before; a graph with one changes its semantic hash whenever a policy or phase changes. The compiled subset admits exactly `curve: "progressive"`, `returnRule: "cancel-on-return"`, `decay.expires: "phase"`, all four axes, and entry cadences of kind `Once`, `After`, `Every`, `Gate` or `Until`; anything else refuses with a field path. Phase envelopes are restrictions relative to the final base, not to the previous phase: an allowed effect must be inside the base's allow patterns and outside its denials, a resource limit cannot rise or create a positive allowance, expiry cannot extend, and denials, evidence and revocations accumulate. A phase that would widen refuses with `AUTHORITY WIDENING`. `present` and `expired` are reserved phase identifiers, and a non-discretionary phase must declare `inFlightOnReturn: "finish"`.

The fixture host that proves the curve is a bounded interpreter of emitted data. A resident consumer must select one named policy, register `dotln.presence.phase-ready@1`, `dotln.presence.returned@1` and `dotln.presence.interrupt-phase@1`, enforce current presence and capability, count actual files and lines against `scope.changeSize`, spend `scope.budget`, correlate episode outcomes by identity and arm, project a return before a due pulse or outcome at the same recorded time, and execute finish or kill dispositions. `scope.changeSize` and `budget` are not compared with the effective envelope at compile time. `expired` is left only by a recorded return followed by fresh absence. Compile-time availability is a snapshot and must be rechecked before dispatch.

The harness runtime snapshot now fingerprints the compiler's artifact-identity module. A compiler-only version change installs a fresh immutable snapshot and regenerates the hooks against it; previous snapshots stay on disk. Rebuild and regenerate the harness from reviewed source when updating an existing installation.

- Fixtures and tests: `packages/skeleton/fixtures/wo067-presence.json` is the three-phase policy (probe one file under `repo.inspect`, widen three files, peak eight files equal to the base); `packages/compiler/test/presence.test.ts` pins narrowing, refusals, views, the exact Seiri hash and the tooltip; `packages/skeleton/test/presence.test.ts` runs the emitted table with the real kernel authorizer and cadence evaluator.
- Harness: `scripts/lib/harness.mjs` pins `packages/compiler/dist/src/artifact-identity.js` in the runtime files; `scripts/test-harness.mjs` adds the compiler-only-bump regression that re-emits, asserts a fresh snapshot with the old bytes retained, and runs the emitted writer hook; the nine generated hooks and the manifest are regenerated at snapshot `f1f7fc0e67e4664f`; `scripts/lib/evidence-sources.mjs` names the two presence files as common behaviour sources.
