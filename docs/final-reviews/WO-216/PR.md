A structural failure stops the run there and names its remedy: `npm run sync` for a stale generated artifact, the suite and path for a missing declaration or copied-fixture input, the sampled values for host memory pressure. A failed task of any kind stops the scheduler from starting more; running tasks finish and are recorded, the row lists what never started, and `--keep-going` restores the old scheduling for independent work.
