# :sparkles: Add a source-change worker profile with host-observed commits

Both CLI transports now accept a separate writer request that launches a model inside one declared Git worktree with Edit, Write, Read and exactly three Bash commands: the declared test, `git add -A` and `git commit -F` over a host-written message file. Each Claude Code and Codex CLI flag is taken from a named row of the WO-044 writing-worker record, and the arrays are pinned with their row ids. The inspection request, its validator, prompt, parser and both inspection launch arrays keep their activation bytes: across the two transport sources the whole diff removes one import line and one call site, and a fixture pins the arrays, the prompt and the source blocks.

The result keeps the six worker-reported envelope fields and adds two host observations: `observedCommit` (`sha`, `branch`) only when `HEAD` moved between launch and exit, and `observedDenials` from Claude's `permission_denials` array or `unavailable` for Codex, whose JSONL carries no denial field. A model that reports its own commit is rejected, and the worker store retains the observations across physical retries while refusing request-key drift. The validator refuses an inspection intent, a read-only or empty writable mount, a missing `repo.write` or `git.local` allowance, any remote, credential, settings, sandbox or wildcard effect in the allowed lists, a test command with a shell metacharacter, and a message path outside the mount; host preflight refuses the launchpad checkout, a non-worktree directory, a subdirectory, a path outside the configured parent and symlink aliases; construction refuses the record's ambiguous or unavailable rows by name (C-W1, X-U2, X-W3).

Every writer episode in this order is a process double against a real scratch worktree, and the wire tape is synthetic in the recorded field shapes; no live writer was launched. The sandbox is not the containment boundary (C-W6 and X-W6 observed sibling writes), so target governance and post-exit checks remain WO-052's host work and WO-053's live proof. Two verifier findings are carried to WO-053 unchanged: the Claude writer launch does not pass `--settings '{"autoMemoryEnabled":false}'` as the inspection launch does, and the Codex writer retains `shell_environment_policy.inherit="none"` with the shell enabled; both are untested under a live launch. Two observations go to WO-052: a message path outside an ignore rule is staged by the worker's own `git add -A`, and the authority expiry sits inside the durable retry key. The order's operator-authorized ideation breakout adds two document-only planning candidates (local-model usefulness experiments; guided operator work orders) and their ledger entries; it authorizes no setup, launch or allocation.

Validation: `npm test -- --review` passed all 25 suites (69 fresh tasks) in 597.46 s outside the sandbox; `npm run test:docs` passed all 17 suites in 150.86 s; publication, harness-bundle, meta and release-surface checks are current; `git diff --check` is clean; only `@dotln/skeleton` moves, 0.19.0 → 0.20.0, with no dependency change.
