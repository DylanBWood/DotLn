What an operator or an instance meets differently. The kernel admits a new command, and a new `CommandPersisted` append, only with a non-empty `commandId` and `workstreamId`, an `Act` intent with a non-empty effect and a JSON payload. A malformed one raises `CommandAdmissionError` with a `persist/malformed/<field>` trace before anything is stored, and the append re-checks the record it decoded, so a value that serializes differently cannot store an incomplete command; old logs replay exactly as before ([D016](../../evidence/WO-220/decisions.md#wo-220-d016)). A rerun that re-observes an unreceipted source-change commit after an interruption or a crash now closes the command with the same typed `host-admission-<check>` refusal a fresh return gets, instead of an untyped host failure, and a pending signal still leaves it undecided ([D007](../../evidence/WO-220/decisions.md#wo-220-d007)). Live status shows how a resident-owned continuation ends: authority expiring between steps yields one needs-human hold and retires the actor, a finished continuation appends `intent-resolved`, `intent-refused` or `intent-needs-human` to the indexed phase, an order missing from the index reads `index-unknown`, and the budget line says it counts portfolio actors only ([D004](../../evidence/WO-220/decisions.md#wo-220-d004)). A resident whose intent scheduler finds no work no longer records `ActorUnavailable` for an unbound portfolio actor, while an ordinary portfolio resident and a missing runtime capability still report it ([D020](../../evidence/WO-220/decisions.md#wo-220-d020)). NoOp receipts are keyed by reason, phase and arm generation, so a restart repeats none and a rearm records a fresh one ([D008](../../evidence/WO-220/decisions.md#wo-220-d008)).

The vertical and its review loop. One invocation runs at most sixteen triages and sixteen outward actions (repair pushes and thread dispositions) across inline items and review bodies, then stops naming the next item before acting; a body whose text is unchanged after the loop's own repair push is rebound without spending the eight-body allowance ([D010](../../evidence/WO-220/decisions.md#wo-220-d010)).
