With the heading renamed, it fails differently and more fundamentally: `new capability id worker.source-change`. I restored the executor's exact bytes after the probes; the capability table's diff against `main` is the executor's original six added lines.

**Why this does not route to repair.** An appended section may only *reassess* capabilities a planning pass already judged; introducing a genuinely new id is a planning-subject change that needs a fresh receipt.
