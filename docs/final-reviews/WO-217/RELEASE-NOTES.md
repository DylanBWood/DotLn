## Release overview

Application v0.89.0 takes the 58 register rows that earlier closes boarded on the gate, the runner, the host guard, gate evidence and their fixtures to a terminal disposition each: 38 fixed with a fixture case that fails with only that fix reverted, 19 declined with the harm and a reversal condition on the record, and one left to the operator as a packet at the pull request. For an operator or contributor running the gate, the complete review row now stands only while each of its tasks' latest execution passed, `npm run sync` regenerates only what a checker reports stale and refuses everything else, a host guard that loses its record recovers it instead of stranding every later registration, the scheduler keeps an exclusive suite's full host reservation while lending overlap to measured light peers and leads with failed and newly changed suites, and a failed complete run keeps an addressed log that a close carries to main. The declines keep their known harms visible with the conditions that reopen them.

Audience: operators of this repository and of exported instances who run its gates, close its orders and read its register; the planner who reads the nineteen declines and the fired reopening conditions; the operator who answers the packet.

## Read before upgrading

- **A complete row stands on its tasks' latest executions.** The runner's reuse decision, `findGateCheck` and `resume correct --set productGate` share one rule: a complete `npm test` row supplies a pass only while every task it names has an executed, passing result that finished at or before the row was recorded, every declared suite has a task observation, and no later execution of one of those tasks under any check failed; a later repair that passes the task restores the row. A legacy row with no suite declaration covers only an empty claim. A row main accepted on its own exit code can therefore be refused now ([D012](../../evidence/WO-217/decisions.md#wo-217-d012), [D062](../../evidence/WO-217/decisions.md#wo-217-d062)).
- **Sync runs a writer only on a recognized stale report.** `npm run sync` classifies each check's failure before regenerating: a crash, a timeout, an unavailable check, an unreadable input or an unrelated failure refuses its writer and names the remedy. The classifier recognizes every regenerable checker's real stale report, including the sibling index command, the manifest-hash report, the tag-observation reports and the missing or malformed work-order tag snapshot, which the first verification found refused ([D035](../../evidence/WO-217/decisions.md#wo-217-d035), [D087](../../evidence/WO-217/decisions.md#wo-217-d087)). A reworded checker report is refused until the check is repaired; four regenerable artifacts are covered by literal messages only. An evidence writer or recheck that fails names the unselected orphan revision it leaves behind.
- **The host guard republishes a lost record and retires an unadopted child.** A guard that loses `guard.json` while holding `guard.flock` writes its identity again on the next census, so a registration reuses the live owner; the start path kills the child it spawned when another owner wins, fails or times out, so no waiter is left behind ([D029](../../evidence/WO-217/decisions.md#wo-217-d029)). A live guard running older rules is not hot-swapped; stop it through its idle route ([D022](../../evidence/WO-217/decisions.md#wo-217-d022)).
- **Scheduling.** An exclusive suite acquires the full host capacity for itself and its overlap, so another gate cannot take the reserved lanes; only shared tasks whose every held baseline sample is under 60 seconds and 512 MiB RSS may fill them. Priority leads are 3000 for an unresolved failure, 2000 for sources changed since the last product gate and 100 for older branch changes, so unchanged exclusive work precedes shared branch work; an aborted structural attempt no longer advances the change cutoff; a blocked row cannot hide a ready exclusive; launchpad declares update, export and seeds in that order. Retention was judged on three fresh complete runs at the final identity, median 1,504.559 s against WO-222's 1,668.518 s ([D039](../../evidence/WO-217/decisions.md#wo-217-d039), [D042](../../evidence/WO-217/decisions.md#wo-217-d042), [D077](../../evidence/WO-217/decisions.md#wo-217-d077), [D080](../../evidence/WO-217/decisions.md#wo-217-d080), [D082](../../evidence/WO-217/decisions.md#wo-217-d082), [D097](../../evidence/WO-217/decisions.md#wo-217-d097)). The complete run's duration ranged from 1,503 s to 1,904 s across near-identical subjects, so a later order judged by the same median should expect that variance. No fair cross-gate queue is added: fixed-four clients publish no waiting intent, and a new-client queue alone cannot bound their waiting ([D040](../../evidence/WO-217/decisions.md#wo-217-d040)).
- **Host budgets name their remedy.** A malformed or out-of-range `lane-capacity.json` refuses by record label, problem and repair route, as main refused without them ([D041](../../evidence/WO-217/decisions.md#wo-217-d041)); the structural host screen prints the minimum `memory.gateShare` that would admit the measured peak at the recorded lanes and says when that exceeds `memory.hostShare`; session registrations and bare work use the per-lane task budget, not the whole gate share ([D039](../../evidence/WO-217/decisions.md#wo-217-d039)).
- **Gate markers and records.** A legacy active-gate marker with no birth observation is dead when its process was born after the marker, so a reused process id cannot revive it ([D044](../../evidence/WO-217/decisions.md#wo-217-d044), [D047](../../evidence/WO-217/decisions.md#wo-217-d047)). A failed complete run records its failed tasks' output as an addressed log, and `worktree finish` carries a known failed log to main while dropping passing output at every depth ([D050](../../evidence/WO-217/decisions.md#wo-217-d050)). Host-lane waiting is reported separately from task work in the critical path, and a task whose recorded duration exceeds its span is refused ([D019](../../evidence/WO-217/decisions.md#wo-217-d019)); no recorded row trips that refusal.

## Substantive changes

**Gate evidence and reuse** (`packages/skeleton/src/gate-evidence.mjs`, `scripts/lib/gate-reuse.mjs`, `scripts/resume.mjs`, `scripts/lib/gate-timeline.mjs`). `latestGateExecution`, `gateCheckStands`, `intactGateExecutionRow`, `passingGateResult` and `missingGateSuites` move into the skeleton and serve the runner's reuse decision, `findGateCheck` and the typed product-gate correction; `readGateChecks` reads the hot index before enumerating archives so an eviction during the read loses no row; `recordGateChecks` strips passing output and output references at every depth and, given a source root, hydrates a failed row's addressed log whose hash matches; `gateOwnerAlive` fences a legacy marker by its process's birth; `gateTreeHash` leaves re-included untracked intake directories out of the candidate tree; `gateCriticalPath` charges recorded task duration to work and the rest of the span to waiting.

**Sync and generated artifacts** (`scripts/sync.mjs`, `scripts/lib/generated-artifacts.mjs`, `scripts/check-registrations.mjs`). `checkArtifact` classifies a failure as stale only from the artifact's structured inspection, the explicit `DOTLN_ARTIFACT_STALE` marker or its checker's own report pattern; `syncArtifacts` refuses an unclassified failure before any writer and names a retained orphan revision; the registration check names `npm run sync` for a missing or stale compiled runtime.

**Host guard, lanes and budgets** (`scripts/host-guard.mjs`, `scripts/lib/host-guard-state.mjs`, `scripts/lib/host-lanes.mjs`, `scripts/lib/host-resources.mjs`, `scripts/lib/process-monitor.mjs`, `scripts/structural-checks.mjs`). **Runner and scheduler** (`scripts/test-runner.mjs`, `scripts/lib/suite-evidence.mjs`, `scripts/lib/document-failures.mjs`). An exclusive task acquires a full-capacity reservation that its own lease and its light peers' leases nest under; `lightSuiteNames` requires every held sample to be light; `suitePriorityLeads` assigns 3000, 2000 and 100; `changedSinceLastGate` ignores aborted structural attempts and structural companions; the drain guard considers the first unblocked row; failed gates record an output log; TAP-quoted progress lines are read; registration withdrawal reports its own failure kind; product read logs are relative; fixture environments drop `DOTLN_LAUNCHPAD`; document failure classification skips tasks that never executed.

**Harness host, compiler and console** (`packages/skeleton/src/harness-host.ts`, `packages/skeleton/src/observed-facts.ts`, `packages/compiler/src/harness.ts`, `packages/console/src/console-client.ts`). **Role text** (`packages/skeleton/src/loadouts/contributor.ts` and the generated skills). Fourteen shared sentences are shortened; the reviewer gains the packet rule, the planner the judgment-reuse rule, the executor the queue's lead order.

**Tests and fixtures.** `scripts/test-gate-followups.mjs` holds 37 of this order's controls under `process-debt`; `scripts/test-sync.mjs` drives every regenerable checker's real reports and damages the real inventory; `scripts/test-runner.test.mjs` gains the priority-regression, exclusive-reservation, light-sample, copy-closure and glob-observation cases; the host-guard, observed-facts, off-ramps, verifier-gate-claims, harness, license, target-worktree, release and worktree suites gain their rows' cases; the vertical and publication fixtures dispatch ordinary Git calls natively and keep their Node adapters for pushes, remote-URL observation and fault injection; the five hand-copied control sites use a checked fixture-input declaration; every fixture commit and clone sets `maintenance.auto=false`.
