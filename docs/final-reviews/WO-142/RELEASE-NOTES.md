## Release overview

Reviews since WO-003 kept writing down defects and nominations that no work order owned, and the one place meant to surface them had stopped working: every decision record was harvested as a pending follow-up, so the feed grew from 359 to 399 entries in two days and three planning passes selected nothing from it. This release fixes the feed, gives the three working roles one rule for a defect they meet and do not fix, and then clears the backlog: 51 row groups across planning and release tooling, the four packages, the live documents and local residue. It also moves the application to Node 26 and TypeScript 7 at the operator's request, and carries WO-084's ledger order forward unchanged. It is for the operator and for every planning, executor, verifier and reviewer session that runs in this repository.

## Read before upgrading

**Node 26 is now required.** Every manifest declares `engines.node` as `>=26.0.0 <27` and `.node-version` pins 26.9.0; Node 22 is no longer supported. TypeScript is pinned exactly at 7.0.2 with `@types/node` 26.6.2, and the lockfile gains the compiler's twenty optional platform packages and nothing else. Switch Node first, then run `npm ci`. Under Node 26 the machine-read test output is requested explicitly as TAP, and beacon timestamps keep their encoded milliseconds where the filesystem returns a sub-millisecond remainder; no beacon encoding, event or replay contract changes.

**Seven inputs that were accepted are now refused.** A bare `*` pattern no longer compiles claim-free. An Entropy Reducer lens scope with glob characters or padding refuses, which closes the screen in front of ignored intake. The skeleton CLI refuses an unknown argument where it ignored one. The kernel validates the whole candidate log before an append, so an event whose assigned envelope does not decode is refused before the write. The attribution predicate refuses an `Assisted-by:` trailer and still admits a human `Co-authored-by`. `worktree publish` refuses surplus words after the title where it silently dropped them, so quote the title. Release notes refuse a generated heading shape at every heading level and in setext, list and blockquote forms.

**The Entropy Reducer's support text is versioned on purpose.** Shape-First now states the relationship first, per the operator's correction, so that loadout's semantic hash changes. The recorded run stays as history, and the migration check reproduces the historical hash before proving exactly four authorized changes. No other semantic hash moves.

**The live-gate guard admits more.** While `npm test` runs, a session may now use `tail`, `wc`, `ps`, `sed -n` with a bare line range, and `git --no-pager status`, `log` or `diff` with allowlisted flags (`log` and `diff` also need `--no-ext-diff --no-textconv`). Every form the guard admitted before is still admitted, checked against 55,949 real commands with no regression. `find`, `node -e`, any other `sed` script and every write stay refused. Two harmless shapes are still over-refused: a quoted word containing `*`, `?` or `[`, and any `<` input redirect. An admitted `git diff` can still refresh the index.

**Role text grew by one rule.** Executor, verifier and reviewer each carry 327 more bytes than at activation (21,176, 18,218 and 19,436 bytes, inside their ceilings; the reviewer has 1,044 bytes of headroom). A decision record now reaches the follow-up feed only when its JSON names a `followup` string or a `reopens` object.

**`harness prune` deletes only with `--apply`.** The dead suite cache lives in the shared Git directory, so applying in any worktree removes it for every checkout. On a checkout with many retained close lanes an apply is slow, because it re-checks publication for every lane before each deletion: about twenty minutes was projected for a checkout with 32 eligible lanes. A failed lookup keeps its lane and stops the run, and each run starts from a fresh plan. Markers in the older format with no session ownership, and lanes that hold a nested repository, are kept.

## Substantive changes

**The follow-up feed and the rule that feeds it.** An ordinary decision is a record and stays out of the pending feed; a decision that names a follow-up, or another record stating that a reopening observation occurred, enters it. Existing entries, identifiers and histories are byte-preserved and the decisions index still lists every record. The role rule supplies the writers: a defect met and not fixed is fixed inside the boy-scout bound or boarded as a decision with a named follow-up that the report cites, never left as a sentence in a report. This release used the rule on itself twelve times.

**Planning and lifecycle.** An order carried by a refutation receipt stays carried when only its title's version stamp changes, so activation no longer forces a paid re-judgment. Every state-changing `resume` transition refreshes the work-order index, which ends the first `npm run test:docs` failing after each `verify` or `final review` dispatch; the refresh batches its Git reads so the prompt hook's dispatch takes about 1.3 s where an unbatched refresh ran past the hook's 12 s limit. A stray `.DS_Store` in the control store no longer refuses every `resume` command, while any other stray name still does. A repair requested by a final review records that review as its source. Decision links in the index resolve, and render only when the file exists.

**What a Claude Code session is told about its background work.** A background `Bash` dispatch is journaled, including one the host backgrounds on timeout. `completed`, `failed`, `stopped` and `killed` notices are all terminal, the earliest terminal state and time stand against any later observation, and a notice delivered while the session is idle is read from the prompt itself before the transcript holds it. Replaying 185 local transcripts covering 632 finished tasks gives no wrong state or time, where the previous observer misstated 41 states. Advisories are keyed by identity, so two different advisories in one session both appear once and twenty repeats of one appear once, and an unreadable hook input is no longer counted as an unavailable runtime.

**Packages.** The verifier's 320-character summary bound is now stated in its result schema and prompt, which was a recorded cause of rejected live returns. The refuter's result schema states the requirement its validator enforces, a rejected paid result is kept in the ignored local lane with the path named in the refusal, and a Codex refutation no longer fails in its temporary directory, which is now initialized as an empty repository. A resident change-size budget no longer overwrites a scope budget on a shared key; the smaller wins. `LiveReactorDriver` moves to its own module with the 751-line bound unchanged. The console keeps the cause of a failed collection step and one bad loadout export no longer blanks the Builds panel. The feedback source projection derives its workspace list from the lockfile, so a console version bump no longer invalidates feedback editions.

**Release and contribution tooling.** A lightweight ancestral tag produces a FAIL line instead of a throw, the uncommitted surface check says when untracked source was not compared, and `release check-surfaces` asserts that the skeleton's exact workspace pins equal the workspace versions. The console package declares the three workspaces it imports. A DCO sign-off whose email differs from the author's only in letter case now passes, and a refusal says how to sign off.

**Local residue.** `node scripts/harness.mjs prune` lists snapshots no installed manifest or target receipt pins, markers of ended sessions, the dead suite cache, and a retained close lane only when its order's release is published; a lane's byte inventory is written beside it before the lane is removed, and a live session's files are never touched.

## Progressive polish

Seven diagnostics now name their subject, among them the gate cascade message that hid which dependency failed and cost two full gates in WO-048. Duplicate helpers, dead exports and unused imports were removed; four tie-breaks compare code units instead of the host locale, with existing goldens unchanged; the module-entry guard resolves symlinks through one shared helper; twenty suites gained a specific protection sentence for `--list`. A long tail of test pins was added or made able to fail, with a reverted-subject transcript per group: the release, resume, backup-intake and worktree suites, the subagent cap's concurrency and resume cases, the actor board's verifier-attempt loop, the kernel coupling tripwire and the audit fold messages. The live documents stop describing closed orders as pending and hook refusals as two or three; the README release block is back inside its fifteen-sentence bound at thirteen; package READMEs are version-free; the harness runbook carries a dated version re-check. The per-row list is in the [row dispositions](../../evidence/WO-142/rows.md).
