## Substantive changes

Intake and retained control archival share complete planning, exclusive copies and byte verification before teardown. Binary files, nested and empty directories survive. Differing collisions keep both versions, identical retries reuse preserved bytes, and interrupted copies leave sources recoverable.

Planning-cost freshness follows the recorded cost-bearing inputs. Execution-only commits and merges no longer invalidate unchanged observations; changed inputs, mismatched acceptances, invalid ancestry and observations older than their recorded revision remain refused.

Generated hooks consume piped JSON asynchronously after tracing located a stalled synchronous stdin read. Real-process tests exercise large messages, UTF-8 characters split across chunks and truncated-input refusal. Actual authored-output receipts survive commits and become stale when current bytes change.

The canonical evidence command refreshes the work-order index, decision index, follow-up register and generated harness before fingerprinting. Unchanged projections retain their bytes and modification times. Package tests and fixtures wait for preflights, preventing stale-output refusals from starting expensive workload. Failed review handoffs validate oversized documentation with its publication check while retaining current report and output requirements.
