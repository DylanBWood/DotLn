# WO-236

A Claude Code executor dispatched on a target order now edits that order's registered target worktree without `operator override:`. The kit declares a sixth outside-write grant kind, `target-worktree`, for the executor role alone, under a new operator-granted authority grant, `contributor.target-worktree`, whose reason names the operator's authorization of 2026-10-28 and the planning capture's digest. The hook resolves the grant at every judged outside write from the session's dispatched order (the canonical selection when none is bound), that order's canonical phase, which must be `active` or `repairing`, and the single row for the order in the launchpad's local target registry, whose `launchpad` must equal this physical root; only that row's physically resolved target is granted, and no path is written into the manifest. A missing or doubled row, a row bound to another launchpad, another phase, an unreadable registry, an unavailable lifecycle or a destination beside the target grants nothing and names the withheld cause in WO-168's form. The writer, gate-input, planning-branch and subagent refusals and the five existing kinds are untouched. `worktree start` prints a Claude Code launch line beside the Codex and Copilot ones, all three starting in the launchpad, and its `Next (run manually)` block now starts Codex from the launchpad with `--add-dir` and the target path instead of inside the target.
