# WO-204

The source writer can no longer damage the operator's repository. A source-change episode now runs on a detached worktree whose Git writes land in a private object store under the episode's own administrative directory, with the shared store as a read-only alternate, so the writer's commit moves no shared ref and touches no existing shared object. After the host admits the candidate it packs the candidate's objects from the private store, indexes them into the shared store under an owned keep file, verifies every object and the admitted tree, records `CandidateImported`, and only then creates the episode branch at the admitted commit. The Codex writer's `dotln-writer` profile no longer grants the shared `objects`, `refs` or `logs`; the Claude writer keeps its exact three-command allowlist; and both writers' launch environments now carry the two object-directory variables and two Git configuration pairs that turn rerere and automatic maintenance off, so a commit on a host with rerere enabled creates no `rr-cache` and starts no maintenance child in the shared repository. The owned command route and sandbox profile are removed by two independent, absence-tolerant removals after settlement, the worker result or interruption and the integrity record; a survivor is recorded as `CommandCleanupFailed`, refuses admission and after-testing with `command-route-live` naming its path, keeps the command pending, and is removed by the next run before anything is judged. Before any after-test the worktree is judged against the committed tree: a `skip-worktree` or `assume-unchanged` entry, or a byte, mode or entry type differing from the committed blob, refuses naming the path and restores nothing, while unchanged symlinks, dangling symlinks and gitlinks admit. The verification worktree's Git helper reads under the host's writer-resistant argument set, so a planted replace ref, commit graph or hooks path changes neither judgment, and a private store holding alternates, a commit graph or symlinked storage is refused as `private-object-layout` before any host read. A writer that reports a status other than `completed`, or `requiresHuman`, ends its step `writer-requested-attention` after the integrity and worktree checks and before any effect read, import or branch; a rerun, or a host killed after `WorkerResultObserved`, keeps that end without a second dispatch, and the vertical records `NeedsHuman` with the episode, status and `requiresHuman` in its receipt and never the writer's prose. A settled episode that leaves its candidate unimported locks the worktree's administration against pruning and saves its registration backlink, so `git log --all`, `git rev-list --all`, `git fsck`, `git repack -ad` and `git gc --prune=now` keep working in the target while the candidate stays private and inspectable through the command `SourceChangeCandidateRetained` records; a recovery that imports the candidate restores the registration. `dotln vertical` with a writer killed before commit exits 1 with a pending continuation, and a rerun completes the step with exactly one commit.
