## Release overview

Application v0.99.0 contains the source writer. A writer's commit now lands in a private object store on a detached worktree and reaches the shared repository only through a host-owned import after admission; the writer's command grants are revoked by two independent removals whose survivors refuse admission; the worktree is judged against the committed tree and verification reads Git under the host's writer-resistant interpretation; and a writer's request ends its step as a typed hold the vertical records as `NeedsHuman`. The Codex writer's Git grants and the Claude writer's launch environment are requalified live at the installed CLIs. This closes the three boundaries WO-112 left open and the three findings WO-118's live runs recorded, which WO-083's activation preflight requires closed before its run touches the operator's repository.

Audience: operators who run source-change episodes or `dotln vertical` against their repositories, and contributors changing the source-change host, the writer transports or the verification worktree.

## Read before upgrading

- **Episode branches appear after import.** A source writer's worktree is detached; the host creates the episode branch at the admitted commit after `CandidateImported`, and the writer's commit moves no shared ref. Anything that read the branch while a writer was running sees no branch until admission.
- **A writer's request holds the step.** A writer envelope whose `status` is not `completed`, or whose `requiresHuman` is true, ends the source-change step `refused` with reason `writer-requested-attention`; a rerun keeps that end without a new dispatch. `dotln vertical` records `NeedsHuman` at `source-change`, or at `repair` for a repair writer, with the episode, status and `requiresHuman` in its receipt and never the writer's prose. A `completed` writer without a commit still ends `worker-returned-no-commit`.
- **New refusal reasons name their path or object.** `command-route-live`, followed by the surviving paths, keeps the command pending until a rerun removes the surviving grant; `index-flags` and `committed-tree-drift`, each followed by the path, refuse a flagged, modified, deleted, mode-changed or type-changed tracked file before any after-test and restore nothing; `import`, followed by the commit, refuses an import whose tree differs and moves no ref; `private-object-integrity` and `private-object-layout` refuse a private store whose candidate fails strict `fsck` or that holds anything beyond loose objects and packs. A dirty tree that used to read `host-admission-effect` now reads `committed-tree-drift` with the path.
- **New records.** `CommandCleanupFailed { path, code }` per surviving grant; `CandidateImported { commit, objects }` before the branch exists; `SourceChangeCandidateRetained { inspectionCommand }` for a settled candidate left unimported. The inspection command runs Git with the episode's private object environment. A retained worktree is hidden from `git worktree list`; it is removed with `git worktree repair`, `git worktree unlock` and then `git worktree remove --force` on its path, a procedure no record names yet ([D040](../../evidence/WO-204/decisions.md#wo-204-d040--record-a-retained-candidates-removal-and-its-reachability-window), FUP-30cee01e368d4a23).
- **Writer grants and environment.** The Codex `dotln-writer` profile writes its own gitdir and private store and no longer writes the shared `objects`, `refs` or `logs`. Both writers' launch environments carry `GIT_OBJECT_DIRECTORY`, `GIT_ALTERNATE_OBJECT_DIRECTORIES`, `GIT_CONFIG_COUNT=2`, `rerere.enabled=false` and `maintenance.auto=false`, replacing any inherited `GIT_CONFIG_*` entries. The Claude allowlist and the commit command are unchanged. The Codex commit still meets a non-fatal `packed-refs.lock` denial on every run; it is recorded, not granted.
- **Shared maintenance during a live writer.** While a writer's private HEAD is unimported, `git gc --prune=now` and `git repack -ad` in the target exit 128 safely and lose nothing; they succeed after import and after every settled outcome. A host killed after settlement but before retention leaves `log --all`, `rev-list --all`, `fsck`, `repack` and `gc` failing until the next run of that command retains the candidate ([D004](../../evidence/WO-204/decisions.md#wo-204-d004--import-a-protected-pack-before-publishing-the-episode-branch), FUP-c9b8699c6e654e7c; [D040](../../evidence/WO-204/decisions.md#wo-204-d040--record-a-retained-candidates-removal-and-its-reachability-window)).
- **Known issues.** An error while retaining an unimported candidate replaces the settled refusal with an untyped exception when the writer's gitdir backlink is already absent at settlement; the hold stays durably recorded, nothing is imported and shared Git works, but the vertical cannot map it to `NeedsHuman` (VER-002 F1, [D039](../../evidence/WO-204/decisions.md#wo-204-d039--retention-must-not-replace-a-settled-outcome), FUP-3556f78540a5f22e). A host killed after the writer returns and before `WorkerResultObserved` leaves no envelope, so that rerun admits on the host's own observation. The private-store layout guard admits what git 2.55.0's `add` and `commit` write; a Git release writing another layout reopens [D033](../../evidence/WO-204/decisions.md#wo-204-d033--refuse-private-store-metadata-before-host-reads).
- **Versions.** Application v0.99.0 is a minor release over v0.98.0, retimed from v0.98.0 when the repair integrated `main` ([D030](../../evidence/WO-204/decisions.md#wo-204-d030)). Skeleton moves from 0.68.0 to 0.69.0 for the new object authority, records and refusals; the console pin and lockfile follow; no other component version changes and no dependency is added. The executor role text changes: its two review workers get distinct briefs ([D013](../../evidence/WO-204/decisions.md#wo-204-d013--give-future-executor-review-workers-distinct-briefs)).

## Substantive changes

**Object authority** (`packages/skeleton/src/source-change-worktree.ts`, `source-change-host.ts`, `worker-transport.ts`). The worktree is created with `worktree add --detach` at the base commit, and `prepareSourceObjectStore` writes a private object directory and an ownership record naming the branch, base and store under the worktree's administrative directory. Every host read before import runs under `GIT_OBJECT_DIRECTORY` and `GIT_ALTERNATE_OBJECT_DIRECTORIES`, after `assertPrivateObjectLayout` admits only loose objects, packs and an empty `info` directory; `verify()` checks the detached HEAD against the recorded branch and base and runs strict `fsck` on the candidate head so a private object shadowing a shared one refuses `private-object-integrity`. `importCandidate` packs the candidate's objects with the private reader and indexes them into the shared store with the object environment cleared, under an owned keep file; `verifyImported` checks every object and the tree before and after `publishCandidate` creates the branch against the zero old value. `sourceGit` clears the object environment for shared reads; `codexWriterAccess` grants the private store in place of the shared `objects`, `refs` and `logs`; `sourceWriterEnvironment` supplies both variables and the two configuration pairs to the Codex environment table and the Claude launch environment.

**Command revocation** (`source-change-command.ts`, `source-change-host.ts`). `removeSourceChangeCommands` attempts both owned removals whatever the other did, counts `ENOENT` as removed, refuses both when the route's ownership changed, and returns `{ removed, survived }`. The host settles the process, records `WorkerResultObserved` or `WorkerInterrupted` and the integrity result, then cleans up; each survivor is `CommandCleanupFailed`, and only a clean removal records `CommandGrantsRevoked`. A survivor returns `command-route-live` with the surviving paths and no terminal refusal, so the command stays pending; recovery repeats the cleanup before `verify`, the effect read or any admission.

**Committed-tree judgment and Git interpretation** (`source-change-worktree.ts`, `verification-worktree.ts`). `cleanAgainstCommit` refuses any `skip-worktree` or `assume-unchanged` entry, then compares every tracked entry with `HEAD`'s tree by its committed type: regular files by bytes and mode, symlinks by their unfollowed target, gitlinks left to `status`, every parent directory required to be its own realpath; the untracked-files rule is unchanged. The verification worktree's Git helper now prefixes `HOST_GIT`, so hooks, fsmonitor, replace refs and the commit graph steer neither judgment.

**Writer requests** (`source-change-host.ts`, `scripts/lib/vertical-primitives.mjs`, `vertical-host.ts`). `WRITER_REQUESTED_ATTENTION` is exported; the host refuses with it after the integrity and worktree checks and before the effect read, on the fresh path and in the recovery block from the prior attempt's last `WorkerResultObserved`. The vertical maps that refusal to `held(...)` carrying the refusal and `writer: { episodeId, status, requiresHuman }`, and keeps a `command-route-live` refusal pending across invocations through `RetryableSourceCleanupError`.

**Retention of unimported candidates** (`source-change-worktree.ts`, `source-change-host.ts`). After a settled attempt with no import and no observation, `retainUnimported` writes Git's `locked` file and renames the `gitdir` backlink to `dotln-retained-gitdir`, leaving HEAD, index, objects and files untouched, and the host records `SourceChangeCandidateRetained` with a quoted inspection command once; `publishCandidate` restores the registration after the import is verified and the branch exists, and an imported candidate whose receipt replays stays registered.

**Harness target guard** (`harness-host.ts`). A detached source writer's exclusive writer reservation takes its destination branch from the validated live host route, so the compiled writer predicate still refuses an ordinary detached checkout and a second session.

**Live requalification** (`docs/evidence/WO-204/`). `codex-writer-qualification.mjs` runs a model-free sandbox phase under `codex sandbox -P dotln-writer --log-denials` with a unified-log reader calibrated against every printed control denial, then one `SourceChangeHost` episode through the real Codex transport; `claude-writer-qualification.mjs` runs one episode through the real Claude transport and compares the shared Git directory with its snapshot at process start. Both write relativized records and have helper tests.

**Tests and fixtures.** The source host gains the cleanup matrix for both transports, the index-flag and committed-byte cases, the clean-entry and entry-drift cases, the private-until-import, recovery and maintenance cases, the import-failure case, the retained-candidate matrix, the private-store layout cases, the saved-receipt recovery cases, the four writer-request behaviors with their crash case and the target-writer reservation case; the integrity suite gains the private-shadow attack and pins the forged-graph refusal; the confinement suite gains the sibling-blob deletion under each transport's emulated access; the writer suite gains the Git-configuration commits and pins the grants and environments; the verification-worktree suite gains the planted replace, graph and hooks cases; the vertical suites gain the `NeedsHuman` cases, the pending-cleanup case and the killed-writer CLI case.
