# WO-099

DotLn could verify work after it was done and refute a planning pass before it started, but nothing watched work while it ran, and nothing watched at all once the operator walked away. This change adds the `mission-check` episode: a read-only judge that receives the active work order's contract, the current diff against the base, the last decisions and the vision theses, and returns a typed verdict of `on-mission`, `drift` or `unknown`. A `drift` verdict raises a hold that refuses every unattended dispatch and records one `MissionDriftObserved` correction, and only a human answer or a fresh passing judgment over changed work retires it. The resident fires the episode on the Contributor policy's cadence, so the supervision runs without a terminal.

**The judgment is the host's, not the model's.** The capsule is pinned when the actor is declared and completed with a dispatch-time observation, and the whole capsule is hashed, so a contract edited mid-episode still differs from its pin. The host derives the verdict from supported findings: structural drift the capsule proves is added whatever the worker returns, an unsupported finding refuses the entire result into `unknown`, and a claimed drift naming nothing is `unknown`. A judge that restates a host-derived finding keeps the host's proof in the hold and in the correction a returning human reads. When the model episode fails outright, host-proved drift survives rather than collapsing into an empty unknown hold. The episode carries `repo.read` as its only effect, so the Contributor build hosts the cadence inside its existing base authority.

**The capsule is complete or it says so.** Every changed path is named, tracked or untracked, or the observation refuses; diff text is carried a whole path at a time with unfitted paths listed in `omittedPaths`, and no `on-mission` can be recorded while that list is non-empty. Reads stay inside the canonical worktree, and an untracked symlink is represented as a link rather than followed into outside-worktree bytes. Ignored work is detected without exporting it: Git's directory-collapsed ignored inventory is pinned as salted SHA-256 path ids plus lstat metadata hashes, so changed ignored entries are visible while ignored names, bytes and the salt never cross the model boundary.

**The live row.** With the operator away before and after, a detached parent with no terminal ran the resident, which fired the cadence into a Codex `gpt-6-astra` episode judging a session whose diff edited a file outside its declared surfaces. The verdict was `drift` over two findings — the host-derived surfaces clause and a non-goals clause the live judge found on its own — which raised the hold, recorded one correction, refused the next dispatch naming that hold, and released on the human answer, in 18.8 s. That is one synthetic worktree and one planted drift, recorded as shapes with no transcript, path or session identity filed. It promotes `runtime.resident` to demonstrable and live-evidenced, and the remaining gate stays written: no unattended hour, no repair loop, no dependable-scope claim.

**Validation.** `npm test -- --review` passed **29 suites, 0 failed, 431.44 s, 73 fresh tasks**, run at final review after the whole subject was staged. `git diff --cached --check` is clean. No dependency is added; the only `package.json` movement is the internal `@dotln/skeleton` bump to `0.33.0` and the matching console pin. A fresh feedback evidence edition (WO-099 revision 005) and authority edition (revision 004) are minted because runtime source changed. This is a minor release, `v0.37.0`, retimed from the collided `v0.36.0` target under the order's existing classification.

**What a reviewer should know.** Five verifications failed this order before one passed, and the sequence is the substance of the review. VER-001 failed on command binding, automatic clearance, the diff bound, historical identity and stale evidence; VER-002 on host-proved drift discarded when the model episode fails, and a symlink reaching outside-worktree bytes; VER-003 on capsule overflow breaking observation before a hold is recorded, and an unreadable decision history silently replaced by an empty one; VER-004 on ignored work never reaching the capsule while the judge is told the path list is complete, and a judge replacing the host's reason in the hold; VER-005 on a defect entirely inside the fourth repair's own new code, where the ignored-entry baseline counted the project's build output as out-of-surface work, so one ordinary `npm run build` turned the supervisor into a hold nothing could retire. Each repair carried its own regression and VER-006 reproduced them. The order's eight implementation files were still untracked at final review, so an ordinary `git diff` reports them as deletions; the review compared each file's blob hash against the verified checkpoint instead, and all eight match, as does every tracked source file. Final review changed no source and recorded one harness defect it met without fixing: process-cost counters are structurally unavailable on `codex-cli`, because no Codex path calls `harness begin`, which is why four of the six verification reports carry no token counters while the two Claude-run ones do. That is boarded up as D035 with a named follow-up and needs its own order.
