## Release overview

The three independent reviews of an execution or repair now end. Round one is three reviewers over the whole diff, round two is each reviewer whose findings were fixed rechecking those fixes alone, round three is one combined worker over what changed after that, and then the executor judges the remaining delta itself; a recheck admits a new finding only when it breaks an acceptance criterion or a behavior `main` had. One kit command, `npm run worker -- review`, launches a review worker on Codex or on Claude from either host with a canonical brief rendered from the role text, writes a report the verifier reads into the order's reviews lane, and counts the launch. Every worker use now counts against `subagentCap`: each launch by host, each re-task (a `SendMessage` or an `Agent` call resuming a known agent) and each worker a kit command launches. A review or refutation worker that starts a test-runner gate is refused and told to probe one test under the bounded wrapper. The reviews lane outlives the worktree: release close moves it into the order's retained lane beside its journals. This release is for instance operators, executors, verifiers and reviewers; the operator's phrases are unchanged.
