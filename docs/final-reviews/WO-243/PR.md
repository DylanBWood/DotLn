# :zap: Closeout checks follow what an order changed: a target-only order no longer pays the launchpad's complete run, while launchpad machinery changes and resolved machinery conflicts still do (v0.120.1)

The checks an order owes at its closeout are now one selection, `closeoutScope` in `scripts/lib/closeout-scope.mjs`, and every reader names the same checks: the executor's and the reviewer's briefings end with it (a target order's verifier's too), `npm run resume -- briefing` prints it again as the order stands, `worktree integrate` prints it as owed by this order apart from what main's merge touched, and `implementation-ready` and `repair-complete` record it as one advisory. Every order owes the launchpad document gate. A launchpad order also owes one complete run, its own repository's gate, exactly as before. A target order owes its registered target gate, with `--review` when a criterion names a review form, and the complete launchpad run only where its launchpad changes reach what that run judges: launchpad source or configuration, a kit file, a declared input of a suite the complete run executes, or a record the gates read as input such as `docs/control/budgets.json` or `docs/evidence/current.json` and its editions; a machinery conflict it resolved at integration, even where the resolution kept main's bytes; or a criterion that names `npm test`. Paths main's merge brought in unchanged are main's, gated there, so an integration that only adopted main's kit changes adds no run ([D003](../../evidence/WO-243/decisions.md#wo-243-d003--one-closeout-selection-three-readers), [D004](../../evidence/WO-243/decisions.md#wo-243-d004--what-counts-as-the-orders-launchpad-change-and-how-a-path-is-classified), [D005](../../evidence/WO-243/decisions.md#wo-243-d005--a-criterions-words-take-precedence-over-the-changed-paths)).

Unknown scope keeps the old behavior. An input the selection cannot read or classify (the order, its registration, its activation base, an integration receipt, the runner's suite declarations or a path outside the known launchpad locations) keeps the complete run and names the uncertainty in its printed reason; the selection runs no gate, supplies no passing row and adds no refusal, and completion still consumes only the rows its criteria name. The integrate helper's single "affected checks" list, which the fork's executor read as a duty, is replaced by two: "Affected by main's merge" names the launchpad machinery suites main's change touched from the old head to the main commit taken in and nothing to run, and "Owed by this order" is the selection, spelled for the target worktree of a target order; the no-op path prints the owed list after "took in nothing" so the executor reads it at the closeout point whether or not main moved ([D007](../../evidence/WO-243/decisions.md#wo-243-d007--the-integrate-helpers-two-lists)). The executor's run and handoff steps, the reviewer's run and report steps and its integration sentence, and the target clause the execution roles share now read the selection; product 07 §Preflight before the full gate and §Independent workflows and integration and the kit guide's §What runs here, and what does not state it as built ([D011](../../evidence/WO-243/decisions.md#wo-243-d011--write-backs-product-07-and-the-kit-guide-state-the-built-selection)).

Why it matters: the fork's WO-019 changed no launchpad code, its criteria named the target gates and the document gate, and its executor still started the launchpad's complete run on the role text and the helper's print, stopping it on the operator's question (the target's WO-019-D031). The selection costs about 50 to 75 ms per briefing read on the fixture orders, and a target-only closeout loses one complete run whose median over core's last fifteen passing review runs is 45 min 9 s; a mixed order's closeout is unchanged ([D009](../../evidence/WO-243/decisions.md#wo-243-d009--the-closeouts-measured-cost-before-and-after)). An order already active when an instance takes this release re-runs nothing: its next briefing or integration prints the selection from its current changes.
