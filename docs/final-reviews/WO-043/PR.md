# Work orders declare typed dependencies, so activation refuses only a real unmet prerequisite

Every open work order now carries a marked JSON block declaring each dependency with a relation and a one-line reason. `scripts/lib/dependencies.mjs` parses it, and one projection serves the generated index, the selected `status --json` and `resume activate`. Activation refuses before any event or checkpoint when an entry is unmet, naming the entry and the corrective action; historical citations, references, waivers and supersessions never block, and orders without a block keep a labeled conservative token view that never blocks. The generated index no longer says "blocked" for any closed or historical order.

The migration transcribes the 2026-09-08 critical-path graph into all 85 open orders (245 entries) and records the comparison in `docs/evidence/WO-043/migration.json`; the 40 closed and historical authorities are byte-identical to main. WO-052 projects `hard` on WO-049, WO-050 and WO-051, the umbrella records project only `superseded` entries, and the planning-continuation gate admits only this reviewed transcription, refusing omitted or changed relations, an unreviewed waiver or a changed seed.

Operator-authorized expansions during the repairs make session token measurement mandatory (one collector for `harness usage`, the Claude Stop hook, `meta --collect` and all four completion commands; missing, stale or foreign counters refuse a handoff while Stop only advises), equip Process Cost and Goal Alignment as shared supports in all six roles for both harnesses through an additive role-set adapter, project the `scope expand:` and `conversation only:` contract into every generated role target, print the equipped executor duties and the queue on ordinary `next` and `fix` with completion refusing unresolved queue items, and centralize the current evidence editions in `docs/evidence/current.json` for the evidence commands and the console. Compiler 0.9.1, skeleton 0.15.1 and console 0.1.4; the kernel, lifecycle event schemas and the feedback schema are unchanged; no new dependency.

VER-001 found one publication-row overclaim, VER-002 found four repair findings (the command contract absent from generated instructions, an unauthorized floor rewording, a stale cold-start table and a 44% understated executor meter), and [VER-003](https://github.com/DylanBWood/DotLn/blob/main/docs/verifications/WO-043/VER-003.md) passed after both repairs, reproducing every recorded token figure from its source counters. [FINAL-001](https://github.com/DylanBWood/DotLn/blob/main/docs/final-reviews/WO-043/FINAL-001.md) records the review: the canonical evidence gate passed on the review tree, the 84 migrated files are pure block insertions, and the index uses "blocked" only under Open.
