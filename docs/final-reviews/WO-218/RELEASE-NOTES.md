## Release overview

Application v0.87.0 takes forty-five boarded register rows to a terminal disposition: thirty-nine are settled with a fixture case that fails when its own fix is reverted, and six are declined with their harm, evidence and reversal condition recorded. The rows span the instance lifecycle, the export and kit, publication, release close, the starter, worktrees and the target-order lifecycle, including the 33 findings of WO-221's two final reviews. For an operator the visible changes are a registered-target publication route that admits only the node publish helper bound to main's committed authority, a target close that checks access, symlinks, path-list size and tracked-path collisions before it deletes anything and can keep the base checkout's output, a release close that serializes, retries after main moves and keeps an immutable attempt history, a starter refresh that checks the forge and the sibling tag before it pushes, instance identity that comes from configuration rather than the kit, an explicit continuation for an interrupted stash application, and publication link rewriting that handles encoded and nested links. The final review added eleven bounded repairs of defects its reviewers found in those surfaces, led by a session-root guard that an unnormalized temporary directory could disable.

Audience: operators of this repository and of exported instances who run `worktree start`, `worktree publish`, `worktree integrate`, `release close`, the starter refresh or the publication check, and the planner who reads the register after this batch.
