## The first lab contract should be concrete

Use the already evaluated Once/After/Every/Gate/Until/Backoff subset and
Done/Emit/Invoke/Await/Guard/Sequence where the chosen scene needs them. Verify
the exact contract at implementation; this is not authorization to make every
cadence or program kind executable. Start with one active mechanic if sufficient.
Ten independently driven actors and one multi-active actor are different scope.

The existing loadout statechart codec and static compiled diff are useful inputs.
The missing comparison must run two versions against pinned conditions and
return event/decision paths, first divergence and requested/attempted/observed
effects. Keep declared resource costs, observed counts and any measured cost
separate. WO-102's temporal corpus and WO-107's profiling are existing evidence
routes to inspect, not claims that the application experience is already built.

Evaluate RxJS as a precise interaction reference or adapter with explicit state,
effect, scheduling and teardown contracts. Keep the kernel framework-independent.
The [24 interaction records](research/interaction-algebra.md) span commitments,
coordination, memory, feedback, adaptation, sensing and actuation. Preserve that
ambition as the vocabulary grows; do not restrict the proposal to UI triggers.
