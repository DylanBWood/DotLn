## Portable ideas retained from the mixed notes

The operator's disposition is granular generalization. Preserve the capability
behind private examples; remove private identifiers, configuration, code and
service details. The old rule-label inventory contains 142 named topics, not
142 inspected rule implementations. Labels alone cannot supply full contracts.
Do not import that implementation catalog or silently turn a name into a rule.

Distinct portable directions include:

- Import a changing ticket artifact through interchangeable connectors.
  Formatting, image placement, discussion and revision can carry meaning;
  interpret conventions per artifact and record OCR/visual disagreement.
- Carry external questions and responses into work without making the operator
  a courier. Communication effects still require their applicable authority.
- Preserve craftsmanship through examples, reusable routines, comparison and
  operator judgment at the design level.
- Separate global, domain, repository and environment concerns so experience
  transfers without applying every rule to every task.
- Retrieve a relevant rule and its related cases on demand; measure context
  burden and missed activation rather than assuming more prose is safer.
- Make rule changes reviewable: preserve the intended correction, nearby valid
  behavior, earlier rejected alternatives and retirement conditions.
- Keep work and inspection available across session/network interruption; show
  observed model/tool capability rather than an unverified UI label.
- Distinguish a working user experience from structural scaffolding, rendered
  placeholders, partial completion and self-reported success.
- Compose events and responses progressively; compare focused bundles with
  broader awareness and use cheaper deterministic mechanisms where sufficient.
- Let a shared host run logical listeners without requiring a separate model
  process for each small reaction. Preserve alternative aggregation/timeout
  choices before selecting runtime machinery.
- Support slower readers and late responses with persistent source-addressed
  records. A compact return view must not delete the detailed research.
- Preserve manual, playful composition when that is itself the desired craft.
  Automating every operator action is not the only measure of product value.
