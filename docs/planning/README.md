# Planning

This directory holds what a planning pass starts from and the records each pass
leaves. A pass is opened by `planning:` and runs the route in the execution
guide's [§Operator-opened planning pass](../product/07-execution-guide.md#operator-opened-planning-pass).

## What a pass reads

- [The sequence](sequence.md): the proposed order of open work orders, the one
  input to the generated work-order index and the refutation subject.
- [The planning map](work-order-map.md): the recommendation and rationale, the
  catalog of human preflight and scope notes, the tracks and dispatch
  dimensions, the status boundaries and the capability progression policies.
  Below its record divider are the dated candidate sections each pass wrote;
  their headings stay as they are because the follow-up register keys on them.
- [The follow-up register](followups.md) and its data,
  [`followups.json`](followups.json): every candidate, deferred item and
  follow-up with its current disposition, generated by `npm run meta` and read
  a page at a time with `npm run plan -- followups`.
- [The capability table](capability-table.md) and the generated
  [cost table](cost-table.json).
- `npm run plan -- documents`: the document kinds, the reader bindings, the
  read census over the last five releases and the red tags this pass disposes.

## What a pass leaves

- Its own document in [`passes/`](passes/), named `<slug>-<date>.md` and
  created by `npm run plan -- start <slug>`. A pass document is a record: dated,
  written during its pass and never rewritten after it. Its red-tag block
  carries the standing documents no reader reaches and no session read; the next
  pass removes or folds each and writes the disposition there.
- A blinded refutation receipt pair in [`refutations/`](refutations/README.md).
- The generated accepted-finding pages of each Entropy Reducer review in
  `entropy-reviews/`.

The dated pass documents that stood directly in this directory moved to
`passes/` under the same names; a link written before the move still names the
old path, and [`document-moves.json`](../control/document-moves.json) says
where each one is. `passes/` also keeps the retired copy of the planning map
and the hand-kept release-history notes product 06 carried before WO-086.
