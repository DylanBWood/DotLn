## Disposition (2026-09-06, planning session; each hold answered before the pass ends)

1. **Hold: WO-039 criterion 6 and WO-040 criterion 4 measure without a
   required direction.** Accepted; changed. WO-039 criterion 6 now requires,
   per role, always-on instruction bytes not larger than the activation
   base's and a mandatory cold-start read shorter in bytes and lines, with a
   role that is not shorter failing the criterion; the residue block is
   bounded to text no unit lowered and refuses procedure a role skill
   already carries. WO-040 criterion 4 now requires the mechanism count
   higher and the prose count lower after the batch, context not larger,
   and fails a batch whose counts do not move. WO-035 gains a redirect note:
   its shorter cold start is reached by removing procedure that WO-039's
   skills carry, not by pruning, and counts only the always-on read.
2. **Hold: WO-033 ships the author's build into every fork by default with
   no criterion that a fork may omit or replace it.** Accepted; changed. The
   Contributor build is declared starter content, not kit law; the overlay
   may replace the identity, unequip any unit, adjust the envelope within
   the fork's own posture, or declare `build: none`; criterion 5 adds two
   fixtures (an overlay that replaces the identity and unequips two units;
   an overlay with no build that re-emits to the floor alone with
   `harness check` passing) and the client README states it first.
3. **Hold: WO-040 commits a row for every intake-named shape including
   employer-specific ones with reasons, and "no intake text" names no
   check.** Accepted; changed. Employer-specific shapes get no row at all,
   only a count per exclusion class; the classification of those shapes
   stays in ignored intake. A hashed deny-token check joins
   `feedback migration --check`: every token of every committed row and
   unit text is hashed and compared with a committed list of SHA-256 hashes
   of the terms `CLAUDE.md` says must not re-enter; the plaintext list is
   never committed; a fixture row proves refusal. Criterion 7 names that
   check and a reviewer read. The same hashed list serves WO-033's
   camouflage lint, whose deny list is now committed only as hashes, with a
   fixture; the refuter's separate warning about republishing terms through
   a plaintext deny list is thereby answered as well.
4. **Hold: WO-041 classifies any finding without a thesis and a row as
   machinery, so violations of §What DotLn is not cannot be reported as
   drift.** Accepted; changed. The verdict rules are fixed in the schema:
   `drift` must name the vision passage it rests on, which may be an item
   of §What DotLn is not, and needs no capability row; `machinery` is for an
   order that names neither. A hold is constructed when any order drifts,
   when none advances a thesis, or when the largest gap names a thesis no
   order touches and no non-goal defers to a named later order. The live
   run's verdict on WO-041 itself is recorded as advisory with the
   self-referential instrument disclosed (criterion 4).
