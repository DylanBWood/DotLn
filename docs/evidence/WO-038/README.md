## Behavior and evidence

The root and three workspace manifests declare Apache-2.0 and `private: true`, and the lockfile records the same licenses. A small `prepublishOnly` command refuses npm publication. `license-surfaces` checks the current bounded workspace layout, exact guard, absent publish-time overrides, license-file hashes, and the legal record's pins, then runs offline npm dry runs against isolated copies of the selected manifests. The probe inherits neither npm configuration nor credentials, checks the specific refusal marker and exit 1, and copies no source files or intake. Committed checks read Git blobs for both static surfaces and probe inputs. Direct offline `npm publish --dry-run` calls from each real workspace directory also returned exit 1 with the same marker, without a workspace-selection override.

The installed npm 10.8.0 returned exit 0 for an isolated synthetic package with `private: true` and scripts suppressed during `publish --dry-run`. That observation motivated the explicit lifecycle refusal; it is not a claim that npm would publish a private package. npm's [package metadata documentation](https://github.com/npm/cli/blob/latest/docs/lib/content/configuring-npm/package-json.md) specifies SPDX license identifiers and `private: true`, and its [lifecycle documentation](https://github.com/npm/cli/blob/latest/docs/lib/content/using-npm/scripts.md) places `prepublishOnly` before packing during publication. Those official sources were retrieved through Context7 for this implementation.

The contribution check uses raw author fields and Git-parsed trailers on every commit in the local `origin/main..HEAD` range. The exact public operator author identity from the license-decision commit is exempt; an outside author needs a matching DCO 1.1 sign-off. Historical base commits are excluded, side-branch commits are included, and the committer or publisher's Git settings do not grant an exemption. The check certifies trailer presence and correspondence, not personal identity or the truth of a contributor's attestation. `worktree publish` runs it before GitHub authentication, branch push, or PR creation.
