# WO-281: the reader's ten tasks

Written on 2026-11-15 in step 1 of the order's execution plan, before any
line of the kit guide was changed. Step 6 gives these tasks, and nothing
else about the order, to one fresh worker, which answers each from the kit
guide (`docs/KIT.md`) as it stands at the base and again as it stands at
the candidate, and names the section it used. The two answer sets are
recorded beside this file for the operator's review.

A task is put as a person who operates an instance would put it. None names
a section, a heading or a decision, and none asks about a behavior the
rewrite changes, because the rewrite changes none.

## The tasks

1. I have the starter's URL and an empty private repository. What do I type,
   in order, to have a working instance, and what should I see when it has
   worked?
2. I need to keep some names out of every commit, and one of them is also an
   ordinary word. Where does the list go, how do I write the two kinds of
   entry, and what happens to a line a branch adds that holds each kind?
3. How do I run this instance's first planning pass, what does it produce,
   and how does it end?
4. An order has been filed. How do I run it from its start to its release,
   what do I type at each point, and how must its pull request be merged?
5. A newer starter release is out. How do I look at what it would change,
   take it and finish, and what do I do with a file both this instance and
   the starter changed?
6. My team's application lives in another repository. How do I register it
   so that the instance can work on it, without any order's record being
   committed into the team's repository?
7. A target order has been reviewed and its change is ready to go to the
   target repository. What does the publish check before it pushes, and
   what do I do when it stops on a word it wants read?
8. `resume: release close` stopped part-way. How do I find out why, what has
   it kept, and how do I finish it? And what if the team squashed the
   target's pull request and edited it at the merge?
9. I want every edit in this instance to run a script of mine afterwards.
   Where do I register that, which events may my hook not use, and what
   happens to it when the kit updates?
10. I want reviews to run on a different model from the one the kit ships
    with. What do I edit, what do I run afterwards, and how do I see what a
    launch will use?

## What an answer holds

For each task: the answer in the reader's own words, as steps where the
task is a procedure; the section or sections of the guide it was taken
from; what the reader could not find or was unsure of; and how many minutes
of reading it took, where the reader can say.
