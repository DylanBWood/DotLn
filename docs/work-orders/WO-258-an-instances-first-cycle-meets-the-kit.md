**Design (scope discipline):**

- Hosts are elections with inference, not a build overlay. Rejected: a
  `build.overlay` entry per host (the axis is where the choice lives: an
  overlay is the instance's equipment choice and already refuses the
  tinkerer election since v0.119.0; a host is a feature row the inventory
  prints with its source). Rejected: inference from the ignored session
  journals (the axis is reproducibility: a fresh clone has no journals, so
  the committed control log and the committed discovery record are the
  record, and an instance that used a host only in unjournaled sessions
  elects it by hand). The effective value is the election when declared,
  else `on` with the row that shows the host, else `off`; an election of
  `false` beside a record that shows the host is respected and the
  inventory says what the record shows.
- The release-close phrase is recorded by the close, not judged against the
  remote. Rejected: the prompt hook fetching `origin/main` to judge
  legality (the axis is effect: a prompt hook reads and never reaches the
  network). The hook journals the phrase as a pending release-close
  dispatch naming the fact the checkout lacks the order's records and
  resolves the release-close role; the close, after the fast-forward it
  already performs, records the dispatch from the pending row through the
  same lifecycle path, so the helper's admission reads it; the operator
  texts still say to update main first, as the plain route.
- One Git floor, declared once and judged where Node is. Rejected: a
  per-call fallback for old Git (`--source` emulated by a temporary
  checkout; the axis is cost against clarity: one refusal naming the floor
  is cheaper than three emulations).
- The starter refresh adds what the export would have written and removes
  what the kit retired, both under the proven-rendering rule the README
  already uses. Rejected: a kit action kind that deletes a file (the axis
  is authority: actions are opt-in and run by the instance; a retired kit
  seed is the refresh's to remove when unmodified, as it rewrites one).
- The empty sequence is admitted. Rejected: product 07 saying the last
  closed order stays until another is filed (the axis is truth: a closed
  order is not proposed work, and the generated index already keeps it).
- The continuation gate compares under the judged receipt's rule, the rule
  the receipt rebuild already follows. Rejected: treating the members as
  order inputs whose absence from the judged set is admitted (the axis is
  what the gate protects: a member filed after the receipt is judged by the
  next receipt, not admitted into the old one).
