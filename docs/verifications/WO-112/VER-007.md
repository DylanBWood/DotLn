### F1 — writers outlive an interrupt; a rerun seals the run as refused

**Route:** operator (the verifier judged it blocking; the operator overrode it
to a pass). **Class:** operator-flow and authority regression in
`packages/skeleton/src/worker-transport.ts`, a declared surface (D017/D028).

This order launches every native writer detached in its own process group
(`worker-transport.ts:1342`, `:115-130`); `dotln vertical`
(`dotln.ts:85-107`) installs no interrupt handler, unlike `presence`
(`dotln.ts:153-157`).

**Observed (executed):**

```zsh
node scripts/harness.mjs bounded -- node docs/evidence/WO-112/verification-007-orphan-probe.mjs
```

The probe ran from 04:36:43.647Z to 04:36:53.135Z and exited 0. On main, the
writer dies with the interrupted host. With the order's launch, the writer
survives the interrupt and is still alive past the host's 2.5 s deadline (last
heartbeat 4,544 ms). The adversary's copy gave the same result.

**Traced, not run end to end:**

1. A rerun while the old writer lives throws `prior worker group is still present` (`source-change-host.ts:522`). `source-change-integrity.test.ts:906` asserts this throw after a killed host.
2. `vertical-host.ts:202-213` records that throw as `refused`.
3. `vertical.ts:719` and `:857-865` seal `refused` as the issue's replayed terminal outcome.

**Expected and repair rule:** in D060's follow-up. An interrupted host kills
the writer groups it launched. A rerun that finds a live prior writer holds
and retries rather than refusing terminally. D028's separate group and
integrity checks stay as they are.

**Limits:** the writer is synthetic. The native CLIs' own budget caps and the
180-second command expiry bound the orphan, but neither stops it.
