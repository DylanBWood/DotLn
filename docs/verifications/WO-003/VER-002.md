The gate is not a single brittle path. Four further in-memory-handover variants each fail,
including the adversarial one that populates the *asserted field itself* from memory. Two
additional mutations confirm the clause's other halves are pinned rather than incidental:
deleting the adapter's dedupe check fails on `adapterEffects`, and dropping the `ep:`/`ws:` prefix
in the kernel's `commandId` fails on the pinned `cmd_5ee0c6d8e207bd25`.

Clause by clause, criterion 3 now reads:

| Clause | Demonstrated by a test that fails when the behaviour is removed |
|---|---|
| recovers via `replayOutbox`/`pendingCommands` | yes |
| **actual re-dispatch after restart** | **yes — newly closed** |
| no duplicate effect at the adapter | yes |
| adapter dedupes on the namespace-tagged `commandId` | yes |

`recoveryLogTransform` is a test-only seam in production source. It is invoked only inside
`if (options.crashAfterPersist)`, and removing the call site leaves the log, traces, timeline and
glyph of both the normal and crash runs unchanged — so it alters nothing when unused. Mutating the
log mid-run does not make the test's other assertions vacuous: `appendEvent` uses positional
`evt_N` ids with no hash chaining and the transform is a 1:1 map, so trace equality with the normal
run (line 90), the empty-`pendingCommands` assertion (line 91) and the `commandId` assertion (line
93) all remain live. This is the second option `VER-001`'s repair checklist named ("expose the
recovery input so the test can assert it was reconstructed rather than handed over").

The ordering the clause turns on — checkpoint *before* `append()` — is pinned in its own right: a
mutation that appends first, checkpoints second, and writes the sha back into the last log line
(so items 1, 2, 3 and 5 all still pass) is caught.

**"Record, never refuse" holds under attack.** 14 hostile inputs were driven through `checkpoint()`
in isolated fixtures — no HEAD, detached HEAD, a linked worktree, a broken linked worktree, a bare
repo, `.git` removed, read-only `.git/objects`, a corrupt `.git/index`, missing `TMPDIR`, and
others. Every one warned on stderr and appended normally; none refused.

**It touches nothing it should not.** A full sha1+mtime snapshot of every file under `.git` before
and after a transition differed only by new loose objects and the one new ref.

**Numbering is numeric, not lexicographic.** With refs `1..12` pre-seeded the next is `/13`;
non-numeric refs under the prefix are filtered by `Number.isInteger` without crashing.

**Illegal transitions append nothing and mint no ref**, for every action and every
argument-validation failure — `requirePhase` and path containment run before `appendTransition`.

**Live evidence, from this verification's own transition.** `npm run resume -- verify` wrote
`refs/dotln/checkpoint/WO-003/2` = `559a353a...`, parented on `5928d81` (unchanged HEAD), subject
`dotln checkpoint: verify WO-003`. Its tree carries the deliverable, `VER-001.md` and the
pre-transition control log — and **excludes the single-copy gitignored raw material**
`docs/intake/notes/wo-003-expanded-ideation-2026-08-31.md`, carrying only the three tracked
`.gitkeep` files. `git add -A` honouring `.gitignore` is what makes the clean-room boundary hold
through the object store, exactly as the addendum predicted. `refs/dotln/checkpoint/WO-003/1`

## Method

Thirteen independent verification dimensions covering the blocking finding, R1, R2, their test
adequacy, the addendum's clause-by-clause acceptance evidence, regression across all thirteen steps
and criteria 1–2, repair scope and commit order, control-plane integrity, evidence-suite integrity,
documentation consistency, the clean-room boundary, and the ideation gate delta. Every candidate
finding was then attacked by two independent agents — one mandated to refute it, one to judge scope
and severity against quoted work-order text — and discarded unless it survived both. 103 agents,
0 errors, 45 candidate findings, 42 refuted. The lead verifier independently reproduced the
criterion-3 mutation, the R2 hazard drill end-to-end with a real secret, the checkpoint object
inspection, and the control projection before accepting any agent's conclusion, and reinstated two
findings the panel had refuted. The repository was not modified by any agent; all mutation probes
ran against copies in a scratch directory.
