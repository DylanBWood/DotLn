- **Criterion.** Scope expansion: "It must preserve explicit interruption and
  operator recovery controls." Documented claims that contradict the behavior:
  - `codex-continuation.md:27-28`: "`Interrupt` and explicit stop/pause

  - the product 07 write-back: "Explicit pause, interruption, analysis and
    override win".
- **Observed.** `codex-continuation.mjs:117-125` recognizes a stop only with the
  anchored pattern
  `/^(?:please\s+)?(?:stop|pause|cancel|abort|hold off|do not continue|don't continue)(?:\s|[.!]|$)/i`.
  My probe copied this worktree's generated `.codex/hooks/continuation.mjs`
  into a scratch fixture shaped like the test suite. It then ran PostCompact

- **Reproduction.** See my probe

- **Likely surface.** `packages/compiler/src/codex-continuation.mjs` (the
