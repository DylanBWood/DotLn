## V5-F1 — blocking: command-path aliases omit the executed input

**Criteria:** 16, 17 and 19. **Severity:** high.
**Class:** task-input binding / unsupported passing claim.

**Expected:** editing a task's entry file invalidates its prior pass. A path
spelling the binder cannot establish must produce conservative fallback or
refusal, never a narrower declared binding that silently omits that file.

**Observed:** a declared task with `inputs: []` and command
`node scripts/../scripts/alpha.mjs` receives a declared binding with empty
`spec.entries`. After an initial complete pass, changing alpha from exit 0 to
exit 13 changes the code identity but leaves that binding unchanged. Direct
execution exits 13. The next complete gate carries the earlier alpha result,
executes no fresh task, exits 0, and passes both `coveringGateCheck` and
`requireGateClaims`.

Reproduce from the repository root:

```sh
node scripts/harness.mjs bounded -- node docs/evidence/WO-213/ver005-path-alias.mjs
```

The retained program asserts the full false-admission sequence, cleans up its
disposable repository, and prints booleans and exit codes. It also proves
that ordinary `scripts/alpha.mjs` binds the source correctly. Additional
direct-command/binding controls reproduce the omission for
`scripts/./alpha.mjs`, `scripts//alpha.mjs` and
`./scripts/../scripts/alpha.mjs`.

**Cause checked in source:** `scripts/lib/task-inputs.mjs` lines 263–294:
`repositoryPath` returns undefined when `safe` rejects interior dot or empty
segments. Filtering removes the word before both entry discovery and the
existing-file refusal. `fromSpec` then accepts the remaining declaration.
The command itself still reaches and executes that file.

**Repair rule:** normalize and validate contained paths before discovery, or
make unestablished spellings unbindable and non-reusable. Preserve containment,
intake and symlink refusals, ordinary spellings, the accepted declaration-based
design and whole-code fallback for undeclared suites. Regress the class with
real child exits and both reuse and lifecycle consumers, not only string
normalization. D067 boards this inside the order and reopens D065's explicit
actual-input-drift condition.

**Limits:** the false claim exists only in the disposable fixture. The audit
finds the actual current review row intact; this does not establish that its
shipped suite declarations use an affected spelling. No false result was filed
on WO-213 and no implementation was changed.
