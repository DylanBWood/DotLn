## F1 — A passing gate's roots stay pinned by copied owner records

**Severity:** high. **Route:** blocking (criterion 6). **Class:** ownership-record propagation. **Repair rule:** an owner record never travels into a copy, clone, archive or Git tree. After a passing row, no root its passing suites created remains. The roots this order's earlier gates left pinned are removed by the lifecycle, without operator hands and without weakening the refusal for an unattributable record. A regression fails when a passing suite leaves a root, including a seed-derived clone. Recorded as [D020](../../evidence/WO-233/decisions.md#wo-233-d020--ver-001-f1-a-passing-gates-roots-stay-pinned-by-copied-owner-records).

```sh
node scripts/harness.mjs bounded -- node docs/evidence/WO-233/verification-001-passed-roots.mjs
```

The probe exits 1. For gate `8fe86269` (the consumed row), 26 system-temp roots the gate marked `passed` still exist: worktree-integration 22, plan-refutation 1, instance-history 1, harness-fixtures 1 and process-debt 1, totalling 1.57 GB. The row's `temporaryCleanup` itself records 45 retentions for a nested owned root, 22 of them for these `dotln-integrate-test` roots.

The cause is in the worktree-integration suite's focused seed (`focusedSource`, `scripts/test-worktree-integration.mjs`). The seed is a `createFixtureRoot` directory whose commit "focused integration seed" tracks its own `.dotln-owner.json`. Every clone (`main/`, `wo998/`) therefore checks out a record whose inode is not its directory's. `git ls-files` prints the record in a clone; both clones carry token `2112e9d0` and inode 760917836, against their own 761209887 and 761212039. `readTemporaryOwner` throws "invalid or the directory was replaced". Gate-end cleanup and `harness prune` then keep the parent forever under the fail-closed nested rule, and legacy backfill never applies because the parent has a record. The census found 110 `dotln-integrate-test-*` roots: 22 from each of this order's five gates (`761c7a01`, `43bff0ec`, `1c880d0c`, `76a6260d`, `8fe86269`), 7.8 GB in all. Every passed gate-fixture root left on the machine totals 128 roots and 7.83 GB. The fail-closed rule is sound (D007). The defect is that the fixtures manufacture records the rule must refuse.
