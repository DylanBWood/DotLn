"Existing direct invocations of the historical audit must use that historical
layout"), fully mitigated by a committed script I executed, and the obvious
in-place fix — editing WO-138's immutable evidence — is forbidden. A one-line
hint in the probe's error message would close the discoverability gap cheaply if
a later order wants it.

than on the file system. D007 records the tradeoff and its reopening condition
