### F2 — criterion 9: untracked listing can falsely report identity

**Severity:** minor evidence-fidelity defect; blocking for the witness claim. **Expected:** a changed legal path listing records `identical: false`. **Observed:** `untrackedListing()` reads NUL-delimited Git paths and hashes `paths.join("\n")`; `widenedWitness()` compares only those hashes. In-memory execution of the current functions with before `['a\nb','c']` and after `['a','b\nc']` gives the same two-path count, the same SHA-256 `ea7fb08b7a2dc4619ffb7c7bb38d95a2047935fa165d71b12efd3852a2e6d0cc`, and `identical: true`. A disposable Git repository independently returned both distinct filename sets through `git ls-files --others --exclude-standard -z`; their hashes under the current join were equal. **Reproduce:** feed those two NUL-delimited listings through the current `untrackedListing`/`widenedWitness` functions. The ordinary add/remove fixture does not exercise this framing case. The witness is observational and does not grant authority. Repair is named in [D026](../../evidence/WO-157/decisions.md#wo-157-d026).
