## Observations, not findings

Recorded for a later pass; none is claimed as a defect and none routes to
repair.

- The stall definition counts host wall-clock gaps including startup and
  finalization, so a cold model start and a stalled tool call are the same
  observation. The packet says so in the table header, and row 10's single
  stalls in three of four attempts are consistent with startup alone.
- `judgeAuthority` short-circuits to `unavailable` on any launch failure before
  it evaluates row 10's completion predicate, which is what produced the
  `claude-on-10` label in Limit 5. A future revision could report both the
  failure and the observed workflow state rather than only the failure.
- The `capacity-unavailable` classifier keys on rate-limit or quota text in the
  child's diagnostics, which are deliberately not retained, so that
  classification cannot be re-checked from the run file alone.
- The probe suite is not in the default `npm test` selection; it enters only
  through the reviewer's `--review` gate or `npm run test:machinery`. That is
  the repository's existing convention for machinery suites, not something this
  order introduced.
