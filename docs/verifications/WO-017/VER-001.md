## Acceptance criteria

**1. Store codec contract — met.** `parseLog` in `packages/kernel/src/store.ts`
accepts only `""` or newline-terminated JSON-object lines and refuses everything
else as `Malformed JSONL at line N: <detail>`; `appendEvent` routes through it,
so `evt_<well-formed line count + 1>` cannot be computed from a malformed log.
Six named tests in `ac2-replay-store.test.ts` pin the partial tail, the blank
interior line, the whitespace-only log, the complete-but-unterminated object,
non-object JSON values, and newline-terminated invalid JSON, each asserting the
physical line number on both boundaries; a seventh proves a well-formed log is
changed by append only by the appended object line and round-trips through
`encodeLog`. The domain model's **Event store** row records the contract.

**2. Outbox ordering — met.** `replayOutbox` remembers orphan results by
`commandId` and completes the command when its persist arrives, rewriting that
result's trace to `["result", "preceded-persist"]`. The named test proves zero
pending commands, the completed entry with `resultEventId`, that exact trace,
and that the one-argument call still returns the same corrected `OutboxState`.
The trace-bearing form is a new overload rather than a breaking signature
change. Duplicate orphan results and never-persisted orphans both stay
deterministic and leave no phantom pending command.

**3. Authority guard — met, all five sub-items.**

- (a) `context.now >= envelope.expiresAt` expires. Both directions are pinned at
  `now = 9` and `now = 10` against `expiresAt = 10`.
- (b) The precedence matrix constructs seven envelopes in which two adjacent
  refusal conditions both hold and pins the earlier one; that covers every
  adjacent pair across all eight rules. I checked each row by hand: in each,
  both named conditions genuinely hold.
- (c) The eight-deep ternary is now an ordered `rules` array evaluated
  first-failing. The original seven rules keep their order; the only insertion
  is `cannot evaluate revocation` before `authority revoked`, which is item (e).
- (d) The authorized branch returns a `DecisionTrace` with
  `reactorId: "authority-guard"`, `branchPath: ["authorized", effect]`, the
  environment inputs actually consumed, and the consumed resource. The skeleton
  records it, and `audit.ts` validates its structure before treating it as
  evidence, falling back to the narrower `authorized-command-persisted` label
  rather than inventing one.
- (e) `revocationConditions?: readonly PredicateRef[]` is evaluated with the
  shipped `predicate()` semantics over the full condition x event Cartesian
  product; `authorize` gains optional `state` and `predicateEnv`, and the
  predicate `KernelEnv` is built from the authorization context's own `now`, so
  there is one clock. Missing inputs, an unknown registry or version, and a

  `authority revoked` after operator return in both the live and replay paths.
  All prior call sites remain source-compatible; both new inputs are optional.
