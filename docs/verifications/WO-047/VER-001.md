## Goal alignment and cost

The order serves the always-on runtime critical path: replay must stay dependable while the application, not the kernel, owns where its RNG and policy live, so WO-050's typed slices are not forced to keep two literal keys at the top level. The promised outcome is observed — ten call sites now project explicitly, and 8,842 complete decision sequences are byte-identical either way — and the change is close to the smallest one that achieves it.

- **Rule beating** was the trap I pushed hardest on, because "byte-identical" evidence can pass without the intended behavior occurring. Two results matter. The fixture corpus cannot distinguish a correct projector from a constant, because every stored stream holds `rngState` at 17 (O3) — so I built the evolving-RNG case myself and confirmed the chain advances and repeats. And the AC3 encapsulation pin is a narrow grep (O1/O2). Neither overturns the criteria as written; both are recorded so the evidence is not read as stronger than it is.
- **Drift to low performance** is where F1 lands. A control that is green on `main` and red on the delivered tree, in a suite no later phase runs, is exactly how a standard normalizes downward. Repairing it now costs one heading edit and two lock refreshes; deferring it costs a repair and re-verification cycle from final review under product 08's own rule.
- **Naive Interventionism / NoOp.** NoOp leaves the kernel guessing at a state layout it does not own and blocks WO-050. The delivered change is additive, default-preserving and reversible; the three alternatives the order named (per-event environment in the envelope, removing the default, a global setter) are all recorded as declined with reasons, and I found no cheaper seam.
- **Shifting the burden** is genuinely improved: application code now owns its state layout instead of requiring a kernel edit per consumer.
- **Policy resistance, commons, escalation, success to the successful, seeking the wrong goal** are immaterial here: no new dependency, no new operator step, no new process, and the outcome claimed is replay independence rather than a claim that typed slices already exist.
