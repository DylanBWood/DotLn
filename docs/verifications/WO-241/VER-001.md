`FEATURES.md` and `list` print says `true`, source `default`. Expected: the
page agrees with the loader. The window is keyed on
`packages/skeleton/package.json`, but a kit release is its tag, and the
skeleton stays at 0.81.0 from v0.113.0 into this candidate. Repair rule:
before the first rename ships, resolve named elections through the loader's
tombstones, and key the window on the kit release. Severity: follow-up. The
production table is empty, so only an injected tombstone reproduces either
defect.

**F5 — the import cycle ([D017](../../evidence/WO-241/decisions.md#wo-241-d017)).**
