## Advisory observations

**A1′ — the T1 schema declares the host's maximum field length but not its
minimum, and one retained cell was rejected on that gap.** `requireString`
rejects a zero-length value, while `taskSchema("T1", …)` emits only
`{"type":"string","maxLength":40}`. In `failure-local-T1-unexpected-input` the
local model blocked correctly — `status: "blocked"`, `requiresHuman: true`,
summary "The receipt reader failed to return the verdict row… Returning blocked
with unknown values for unavailable fields" — but wrote `""` into ten of the
eleven fields and was recorded as `invalid T1 criteriaMet`. That output
satisfies the published schema and fails only an undeclared bound, which is the
condition WO-138-D007 names for reopening ("schema-valid output remains rejected
solely by an undeclared field bound"). Attribution is joint: the prompt
instructs the model to "use unknown for unavailable fields", and it did so only
for `verdict`. `repair.md`'s sentence "Boundary tests prove that the emitted and
host length limits agree" is broader than the test at
`scripts/probes/local-model-role-qualification.test.mjs:293`, which asserts the
maximum only. **Not routed to repair:** no floor, distribution, median, outcome,
qualifying task or write-back changes, T1 is unqualified at 0.1 agreement
against a 0.9 floor, and declaring `minLength` would change the emitted schema
and so the build hash, which D005/D006/D009 bind to a full 38-cell
recollection — a cost far above the defect. It belongs in a follow-up, not in
another matrix.

**A2′ — the T1 unexpected-input cell's description does not say the model
blocked.** `decision-packet.md` records "T1's missing-verdict input produced a
retained typed failure (`invalid T1 criteriaMet`)", which is exact, and the
`reportedOutput` is retained. But placed beside T3's "failed because the model
classified instead of blocking", a reader can infer both cells show a failure to
block. Only T3 does; T1 blocked and then filled fields out of contract.

**A3′ — the factor deltas round asymmetrically.** The same 0.057143 magnitude
appears as `-0.057142` (local T2) and `+0.057143` (remote T2) because the delta
subtracts values already rounded to six places. Cosmetic; it does not cross any
threshold.

**A4′ — a prepared PR body exists ahead of final review.**
`docs/final-reviews/WO-138/PR.md` was generated at 15:19:35.729Z by the release
preparation, before any final-review event in `docs/control/orders/WO-138.jsonl`.
It carries no attribution trailer. It is the reviewer's artifact, not evidence
of this order, and I did not judge its contents.
