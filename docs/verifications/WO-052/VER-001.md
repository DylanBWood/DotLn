   (`HEAD^{tree}` is derived from `HEAD`), but the criterion names both and both
   are in fact unchanged; the redundancy is in the order's own wording.

   both caught (`readFileSync` would throw); enumerating the directory is not
   asked for.

   Refuted: an ordering preference with no demonstrable harm and no basis in the
   order text; `closeCommand()` does check authority before `CommandResult`.
5. *AC3 — no assertion on the persisted refusal event or idempotent re-run.*
   Refuted: both concrete failure scenarios are excluded by code the raiser did
   not read.
