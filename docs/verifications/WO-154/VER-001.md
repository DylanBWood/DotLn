## VER-001-F1 — A rebuilt compiler label prevents retaining or carrying the audit

**Severity:** major. **Criterion:** 2. **Status:** requires repair.

**Expected:** a component release-label-only change has the same behavioral
identity and can retain or deterministically carry the previous live audit
without another live episode, including after compiling the changed source.

**Observed:** `--check` and `--carry` exit 1 with
`feedback contract: compiled policy drift` after rebuilding a compiler label
change. The same source edit passes `--check` before the build. A new process
loading the rebuilt modules confirms `behaviorUnchanged: true` and
`pinsChanged: true`.

**Reproduction, executed in an isolated copy of checkpoint 3:**

1. Supply the built packages and existing development dependencies; run
   `node scripts/build.mjs` and `node scripts/feedback-evidence.mjs --check`.
   Both exit 0.
2. Change only `COMPILER_PACKAGE_VERSION = "0.17.0"` to
   `COMPILER_PACKAGE_VERSION = "0.17.1"` in
   `packages/compiler/src/artifact-identity.ts`.
3. Run `node scripts/feedback-evidence.mjs --check`: exit 0, with
   `Retained live feedback audit`.
4. Run `node scripts/build.mjs`: exit 0. Run the same `--check` again:
   exit 1, `feedback contract: compiled policy drift`.
5. Run `node scripts/feedback-evidence.mjs --carry
   docs/evidence/WO-154/feedback-001 --edition WO-998 --revision 001`:
   exit 1 with the same error. No new live episode was run.

A separate broader probe also moved compiler/skeleton package and lock
labels before rebuilding and produced the same failure. The single-label
case isolates the cause; it is not an external dependency change.

**Cause and test gap:**
`packages/skeleton/src/feedback-selfhost.ts:819` replays the recorded audit
through the current reactor before reaching the normalized policy comparison
at line 828. `packages/skeleton/src/reactor.ts:2546` calls
`assertCompiledFeedback`; `packages/compiler/src/feedback.ts:217` recompiles
the recorded units with the current compiler label and rejects the old
compiled policy. The new comparison is never reached.
`scripts/test-evidence-sources.mjs:328` changes the label and immediately
checks at line 334 using the old compiled output, so its passing case misses
the actual rebuilt path.

**Required repair:** make the edition's historical-audit validation support
the promised rebuilt-label case across the replay layers it reaches, while
retaining refusal of actual policy and judged-source changes. Add a
regression that rebuilds after changing the compiler label and tests both
check and carry. The unresolved defect and named executor follow-up are
[WO-154-D010](../../evidence/WO-154/decisions.md#wo-154-d010--ver-001-rebuilt-compiler-labels-prevent-audit-retention).
