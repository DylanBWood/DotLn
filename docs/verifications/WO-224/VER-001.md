## Findings

**F1 — the unfetched-clone refusal does not name its cause.** This is a
non-blocking diagnosability follow-up.

- **Observed:** a registered clone without `refs/remotes/origin/<baseBranch>`
  refuses `subject --repository` and `review --repository` with `fatal:
  Needed a single revision`.
- **Expected:** a message naming the repository id, the missing ref and the
  remedy.
- **Reproduction:** probe 6.
- **Criterion impact:** none. No criterion covers an unfetched clone, the
  refusal comes before any copy, and `main` had no target route.
- **Rule a repair must hold:** refuse before allocating a frozen copy, and
  name the repository id, the missing ref and the remedy (fetch the base
  branch or name a commit). Never fetch on the operator's behalf.
- **Severity:** low.
- **Disposition:** recorded in
  [WO-224-D017](../../evidence/WO-224/decisions.md#wo-224-d017--name-the-missing-fetched-base-when-a-target-subject-cannot-resolve)
  with a named follow-up, which is now in the register.

**F2 — a target that tracks a top-level file named `docs` cannot be
dispatched.** This is a non-blocking follow-up.

- **Observed:** `targetLensBriefs` turns that file into the scope `docs`.
  The unchanged compiled validator refuses that scope, so the target review
  fails at compile time with no frozen copy left behind.
- **Expected:** target lens scopes are only ones the validator accepts, and
  the census still covers the file.
- **Reproduction:** probe 8.
- **Criterion impact:** none. Criterion 1's fixture target holds, no
  criterion names this layout, and `main` had no target route.
- **Rule a repair must hold:** emit only scopes `validateLensFileScope`
  accepts, keep the whole-repository census and leave the compiled validator
  unchanged. A fixture with such a file must dispatch.
- **Severity:** low; this target layout is rare.
- **Disposition:** recorded in
  [WO-224-D018](../../evidence/WO-224/decisions.md#wo-224-d018--target-lens-scopes-must-be-ones-the-compiled-validator-accepts)
  with a named follow-up, which is now in the register.
