## F1 — Blocking: the check's expected version still comes from a generated file

**Severity:** medium. **Class:** blocking. **Criterion:** 1. This is
VER-001 F1's defect class. The check accepts a false kit version while Git,

**Expected:** `siblings index --check` refuses a hand-edited entry whose kit
version names a tag this repository does not hold at the receipt's commit.
It exits 1 and writes nothing.

**Observed:** a synthetic launchpad holds one receipt at a commit tagged
`v1.0.0`. Replacing `v1.0.0` with `v9.8.7-forged` in both
`docs/siblings/README.md` and `docs/siblings/tag-observations.json` makes the
check exit 0. It prints `NEWER tag evidence for <commit>: v1.0.0; the page
keeps its recorded observation; …`, then `PASS docs/siblings/README.md is
current`. The page's Kit version line keeps reading `` `v9.8.7-forged` ``.
`git rev-parse -q --verify refs/tags/v9.8.7-forged` fails,
`git tag --points-at` the commit prints `v1.0.0`, and the receipt and
declaration are byte-identical. Running `node scripts/siblings.mjs index`
afterwards restores both files from Git. This is the failure VER-001 recorded,

**Cause:** in check mode, `writeRegistry` reads `tag-observations.json` into
`recorded`, and `commitFacts` takes `recorded.get(commit) ?? describeTag(…)`.
For every recorded commit, the expected tag therefore comes from the file.
`readTagObservations` validates only its shape and commit coverage. The check
then calls `describeTag` for each recorded commit, but any disagreement only
prints `NEWER tag evidence`. `.gitattributes` marks the file `dotln-generated`,
worktree integration regenerates it as a pure projection, and the generator
overwrites it. It is a second generated output, not one of criterion 1's
inputs (receipts, kit manifests, declaration).

**Repair rule:** every kit version the check accepts must be one this
repository's Git holds for that receipt's commit. A recorded `tag` must point
at the commit, and a recorded `nearest` must be a tag at or below it. Any
other recorded observation refuses without a write. The unedited later-tag
case (probe case E, and the existing fixture) keeps passing with its original
version. The receipt keeps exactly five fields, and no operator command is
added. Add a regression for the coordinated page and observation edit to an
invented tag. The repair may choose the smallest implementation, including
dropping the observation file if Git checks make it unnecessary.
