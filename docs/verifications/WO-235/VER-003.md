## Findings

### F1 — A real host task notification receives the reminder

- **Class:** a real-host input the fixtures held constant.
- **Criteria:** 1 (the reminder excludes host notifications), 9 (host
  notifications create no reminder) and 10 (the security document and product
  07 state that exclusion as built).
- **Observed:**
  - This session's background `npm run test:docs` completed at
    2026-10-30T00:16:11Z. Claude Code 2.1.312 delivered its notification
    through UserPromptSubmit as a 409-byte `<task-notification>` prompt, and
    the hook added the reply checklist to its additional context.
  - The journal row records route `mid-turn`, routeSource
    `transcript-enqueue`, attribution `unattributed` and source
    `claude-prompt-hook`.
  - The transcript holds a `queue-operation` enqueue row with the
    notification's exact content and no `commandMode`. A user row follows
    whose `origin.kind` is `task-notification`, with `promptSource` `system`
    and `turnOrigin` `task_notification`.
  - `promptRoute` (`harness-host.ts` 1336 to 1399) reads only `commandMode`,
    so it returns `unattributed` from the enqueue branch. It never reaches
    `terminalTaskNotification`, and a copy of that function accepts the same
    409 bytes.
- **Expected:** the Design's rule to exclude host task notifications, on the
  supported host.
- **Why the fixtures pass:** they feed a queued-command attachment with
  `commandMode` `task-notification`, or no transcript at all. The existing case
  for an enqueue row without `commandMode` expects `unattributed`. None
  reproduces the 2.1.312 transcript.
- **Reproduction:** start any background task in a Claude Code 2.1.312
  session. When its completion arrives, read the newest
  `OperatorMessageObserved` row in the session journal, and the transcript rows
  around it.
- **Severity:** blocking. It also means the journal counts the notification as
  an operator message. That classification predates this order, but the
  reminder built on it is new.
- **Repair rule:**
  - On the supported Claude Code host, a task notification receives no
    reminder and journals as a host notification, read from the host's own
    notification metadata.
  - An operator message keeps the reminder, including one that pastes a
    notification envelope.
  - A fixture reproduces the 2.1.312 transcript shape.
