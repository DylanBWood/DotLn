## Findings

**F1 — the document gate does not show the ceiling advisory (criterion 8).** Low severity. It breaks the criterion's text, and it removes the only signal the ceiling now gives at the gate.
- **Observed.**
  - `scripts/docs-check.mjs` prints `ADVISORY <file>: <n> bytes over ceiling; planning resets ceilings` (`:464`, printed at `:531`) and exits 0.
  - `npm run test:docs` runs it as the `docs-check` task. For a passing task the runner prints only `PASS docs-check <s> s`, and it prints task output only for a non-zero exit (`scripts/test-runner.mjs:2297-2311`).
  - The recorded row keeps output only for failed or unexecuted tasks (`packages/skeleton/src/gate-evidence.mjs:876`).
  - So the advisory is neither printed nor recorded.
- **Expected.** "A product document over its ceiling makes `npm run test:docs` print one advisory naming the bytes over and exit 0."
- **Fixture reproduction** (`probe-docs-gate.test.mjs` in session scratch, under `harness bounded`):
  - The setup is a docs root whose `00-fixture.md` is 2 bytes over its entry.
  - Run directly, the real `docs-check.mjs` exits 0 with one advisory line.
  - `runGate(['--document', '--serial'])` from the real runner, with a `docs-check` row on the same script, exits 0. It prints exactly `PROGRESS [docs-check] 0.0 s started`, `PASS docs-check 0.11 s` and `npm run test:docs: 2 passed; 0 failed; 0.17 s; 2 fresh tasks`.
- **Real corpus.**
  - `node scripts/docs-check.mjs` prints its `NEWER local release tags not in docs/product/06-roadmap.md: …` notice through the same loop.
  - `npm run test:docs` showed only `PASS docs-check 15.42 s` for that task.
  - The latest recorded document row's `docs-check` case has no output field.
- **Why the executor's evidence missed it.** The new CLI case in `scripts/test-docs-check.mjs` spawns `docs-check.mjs` directly, not the gate.
- **Rule a repair must hold.**
  - With a product document over its ceiling, `npm run test:docs` exits 0, and its own output carries exactly one `ADVISORY <file>: <n> bytes over ceiling; planning resets ceilings` line for that document.
  - A fixture that runs the document gate through `scripts/test-runner.mjs` asserts the line once and the exit 0.
  - Missing or malformed ceiling metadata still fails the gate.
- **Alternative.** The operator waives criterion 8 through the waive off-ramp, naming their words.
