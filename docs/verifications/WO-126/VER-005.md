Twenty-two rows in all. The routes execute on this host, demonstrated with
harmless analogues only: `pnpm exec git --version` prints `git version 2.55.0`
and `yarn exec echo YARN-EXEC-RAN` prints it (Yarn `1.22.22`);
`git -c diff.external='echo EXTERNAL-DIFF-RAN #' diff HEAD~1 -- README.md`
and `GIT_EXTERNAL_DIFF='echo EXT-ENV-RAN #' git diff HEAD~1 -- README.md`
print through the configured command, the `#` discarding git's file
arguments; `X='echo FIND-RAN'` expands into a program under `bash -c` and, in
this session's zsh tool shell, through `${=X}`. `npm exec` could not be
demonstrated in the sandbox (npm's cache refused with `EPERM`) and `script`
needs a pty the sandbox refuses; both classify identically. The adjacent
shapes the repair covers show where the line falls: `npx git push …` denies
while `npm exec -- git push …` allows; `export X='git push …'; script … $X`
refuses, because the literal is `export`'s argument, while
`X='git push …'; script … $X` allows; `git -c alias.p='!git push …' p`
refuses while `git -c diff.external='git push … #' diff` allows.

**Cause.** `executableInvocations` (`packages/skeleton/src/harness-command.ts:485-486`)
applies `refuseDeniedProgram` only to programs outside `dataPrograms` and
`effectPrograms`. An effect program is classified by `deniedInvocation`
(`:549-627`) from its first operand alone, so `exec`, `x`, `dlx`, the `-c`
and `--call` values, the `-c key=value` configuration values and every later
token are never screened, although `npm exec`, `pnpm exec`, `yarn exec` and
git's `diff.external`, `core.fsmonitor`, `core.sshCommand`, `credential.helper`,
`core.editor` and `core.pager` keys execute their values. `invocationProgram`
(`:365-376`) discards leading assignments after checking only `GIT_CONFIG_*`
for `alias.`, so an assignment value never reaches the floor, and the later
`$X` is dynamic data to an opaque program.

**Consequence.** As F21: `remote.unapproved` and `package.publish` are the
effects the no-commits-before-final-review rule depends on, and the Codex
profile has no other layer. VER-004's repair direction exempted "a known
effect program classified by its operand"; the repair followed it, and the
direction did not account for the effect programs' own command-valued
arguments or for assignments. D020's reopening condition is met.

**Repair direction.** Treat `npm exec|x`, `pnpm exec|dlx` and
`yarn exec|npm` as wrappers that recurse into the child command, as `npx`
already does. Run the literal floor over every leading assignment value and
every `git -c` or `--config-env` value and `GIT_*` assignment; commit
messages, `--grep` patterns and the other subcommand operands stay data. Add
each row above to the fixture beside the controls `git -c core.pager=cat log -1`,
`GIT_PAGER=cat git log -1`, `npm exec -- echo hi` and `pnpm exec echo hi`,
which stay admitted.
