## Findings

**F4 — ordinary failure wording is still classed new and walked to publication (criterion 5).** High. Class: correctness.
- Observed: `baselineClass` (`vertical.ts:456-505`) misses each of these:
  - an error status unless "return(s)" or "respond(s)" precedes it;
  - "is not working" when contracted;
  - `can't` and `doesn't` with the U+2019 apostrophe;
  - a failure verb when a modal appears earlier in the same sentence, even across a comma or colon.
- `baselineStoryClass` (supplied current-behavior observations) and the host check (every active statement) share that vocabulary, so a miss is silent on both sides.
- Reproduction (my bounded probe, DotLn session scratch `root/composed.mjs`, outputs `root/c1.out`–`c5.out`):
  - Bodies: "Login isn't working", "Users see a 404 on the settings page", "Login can’t complete" and "This should be fixed, uploads fail for large files". Each is followed by ": make `fixture.txt` contain changed by synthetic worker." and supplied as a current-behavior observation.
  - Each recorded `storyClass: new`, host kind `new`, `findings: []` and `outcome: walked`. All 14 steps completed with 1 writer launch and 1 push, the body read "Deliverable-ready: ready; every applicable item is evidenced." and the run resolved.
  - The control "Login is not working" took the defect path with `outcome: reproduced`.
- Group A's direct probe also found these walked in both statement classes:
  - "Checkout shows HTTP 500.";
  - U+2019 "doesn’t";
  - "threw";
  - "We must fix this: the export fails…".
- This is WO-180 D013's hazard, which the order's Observed gap names. It is also D018's reopening condition.
- Rule a repair must hold: F3's rule stands, and a failure assertion is never silently new. The full rule is in D021's follow-up; in short:
  - every inflection and contraction of VER-001's named categories is covered, with either apostrophe;
  - an error status counts wherever an active statement names one;
  - a modal suppresses only the clause it governs;
  - a composed fixture per group asserts the class, its source, and the reproduction or the finding.
  - Wording outside those categories (time out, loses data, does nothing, won't, stopped working) is a recorded follow-up, not a failure. The exception is a repair that holds an unrecognized current-behavior observation as unclassified.
- Alternative: the operator waives criterion 5 with `npm run resume -- waive 5`, naming their words.
