be reported as an existing failure solely because it uses `thrown`.

only the immediately preceding text, not the negated passive subject.

that issue body with `failureAsRequirement: true`; run through baseline with
an advancing clock. The five-case operator probe reproduced this hold.

Repair rule: preserve positive passive failure assertions and earlier negated
controls while keeping a negated failure subject from producing a failure
finding. This is inside `vertical.ts` and follows Adjacent Repair. It does not
fail another criterion's declared set. D023's separate accepted ambiguity
