# DotLn-Enterprise-Starter

This repository is a launchpad instance exported from DotLn core, ready for
its owner's projects, work orders and evidence. Start at
[docs/OPERATOR.md](docs/OPERATOR.md), which `node scripts/launchpad.mjs
commands` prints before anything is installed: the commands that set an
instance up, run an order and take a release, step by step, with what to
look for and what to do when a step fails. The [kit guide](docs/KIT.md) is
the reference behind it; the [map](docs/README.md) names each document root
and its convention; `UPSTREAM.md` records the kit's provenance.
